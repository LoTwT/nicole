# 产品定位与范围

概要：

- Nicole 是一款轻量的桌面 Markdown 写作应用，面向个人文章和文档。
- 文件保持普通 Markdown 源码，应用不改写格式。
- 本文规定命名、范围、功能分期、平台优先级和已定决策。

## 定位

Nicole 是一款**轻量的桌面 Markdown 写作应用**，主要用来写**个人文章和文档**。它基于 [MyGo](../references/mygo.md) 的 Web 模式：界面运行在系统 WebView 中，后端逻辑用 Go 编写；运行环境的细节见 [MyGo 参考](../references/mygo.md#运行模式)。

文件就是普通的 `.md`。**源码始终保持干净**：应用不得在保存时悄悄改写格式，文件要能继续用 git 管理、用其他工具打开，或直接发布。这条约束也决定了编辑器的实现方式（见[编辑模式](editor-modes.md#单一编辑器内核)）。

## 命名

### 名称与出处

英文名 **Nicole**，仓库名为 `nicole`。

名字取自《原神》角色尼可·莱恩（魔女会，代号 N）。在世界任务《艾伦·史密西，菲谢尔的作者》里，尼可借仙灵之力，让“想成为小说家的人”在睡梦中替笔名“九老师”写作；她的原话是：“只要是存在着创造世界的梦想，就会浮现的作家人格。”

中文名见[已定决策](#已定决策)。

### 宣传语与图标

宣传语候选为“只要存在着创造世界的梦想”，尚未定稿。

图标已确定为**仙灵与羽毛笔融合**：主体采用琥珀金与暖橙，保留包裹光核的卷曲外壳、细长飘带、柔光和半透明层次；尾部用弯曲羽轴与少量不对称羽片表达羽毛笔。

深浅版沿用同一主体设计与配色，通过背景区分：

| 版本 | 背景 | 定稿原图 |
|---|---|---|
| 深色 | 深靛蓝 | [icon-dark.png](../../assets/icons/icon-dark.png) |
| 浅色 | 略带灰紫的冷浅灰 | [icon-light.png](../../assets/icons/icon-light.png) |

两版均为内置 imagegen 生成的 1254 × 1254 PNG 原图，最终编辑提示词见 [icon-prompts.json](../../assets/icons/icon-prompts.json)。原图与提示词作为构建素材保存，不随应用分发；导出、原生打包与界面接入见[开发：应用图标](../development.md#应用图标)。

应用内另用[透明品牌标志](../../assets/icons/brand-mark.png)：保留仙灵、羽毛笔和暖色主体，移除整块圆角底板，以同一份 PNG 融入亮暗画布。带底板的图标用于原生应用与 favicon，保留品牌底色，无需与编辑器画布同色。

### 重名检查

| 渠道 | 结论 |
|---|---|
| npm | `nicole` 已被一个 2022 年后不再维护的 TSX 模板库占用；包名改用 `@ayingott/nicole` 或 `nicole-app`。 |
| GitHub | 没有同名的知名应用。 |
| Homebrew | 没有同名 cask。 |

### 版权边界

可以使用 Nicole 这个名字，但不使用游戏立绘、官方美术或“原神”字样，包括产品界面和宣传物料。

## 范围

| 项 | 结论 |
|---|---|
| 代码编辑器能力（LSP、跳转定义等） | **不做**，太重。 |
| Markdown 写作体验 | **最优先**。 |
| Git 相关 | 后续阶段：调用 git CLI，并提供渲染后的 diff。 |
| 性能和低占用 | 硬性要求，预算见[性能](performance.md#预算)。 |

## 功能分期

### P0

- 打开文件夹作为工作区
- 文件树：显示所有文件，支持新建、重命名、移到废纸篓；非 Markdown 文件打开为无法预览的占位页（见[界面与交互](ui.md#文件树)）
- 标签页（见[界面与交互](ui.md#标签页)）
- 设置标签页（入口和已确定的设置项见[界面与交互](ui.md#设置)）
- 打开工作区之外的单个 Markdown 文件（见[界面与交互](ui.md#打开工作区之外的文件)）
- 三种编辑模式（见[编辑模式](editor-modes.md)）
- Slash 命令（见[Slash 命令](slash-commands.md)）
- 粘贴和拖入图片：存到 `assets/`，插入相对路径（见[工作区与文件](workspace.md#图片)）
- 大纲
- 自动保存（见[工作区与文件](workspace.md#保存)）
- 崩溃恢复（见[工作区与文件](workspace.md#崩溃恢复)）
- 查找替换
- 全文搜索

### P1

- 表格可视化编辑
- KaTeX 公式
- Mermaid 图
- frontmatter 表单
- 链接补全：`](` 形式的链接补全，以及 `[[` 的识别与补全（插入标准链接，见[已定决策](#已定决策)）
- 重命名文件时自动更新引用
- 专注模式和打字机模式
- 字数统计和阅读时间
- 导出（见[已定决策](#已定决策)）
- 主题和自定义 CSS（见[主题与字体](theming.md)）
- 多根目录：在同一个窗口里同时打开多个文件夹（见[界面与交互](ui.md#根目录)）
- 标签页拖动排序

### P2

- 渲染后的 diff（Git）
- 中文排版优化：中英文之间自动加空格、标点挤压
- 反向链接面板（见[已定决策](#已定决策)）

## 平台优先级

1. **macOS**：优先开发和验证。
2. **Windows**：其次。
3. **Linux**：最后。WebKitGTK 相对偏弱，且其自定义协议不能播放音视频。

## 已定决策

| 决策 | 结论 |
|---|---|
| 中文名 | 暂不设置；以后需要本地化显示名时再添加。 |
| 双向链接 | 默认插入标准 Markdown 链接 `[标题](./另一篇.md)`；能识别 `[[ ]]`，但不主动生成；反向链接面板放到 P2；不做关系图谱。P1 的 `[[` 补全按此执行：识别并补全，插入标准链接。 |
| 导出 | P1 支持 HTML、PDF 和复制为富文本；公众号、静态站点等去向在实际需要时再加；不对接博客 API。 |
| 模板与工作区配置目录 | 用户模板和以后的工作区配置统一放在 `.nicole/` 下；`snippets/` 的用法见[Slash 命令](slash-commands.md#用户模板)。 |
| 界面布局 | 采用“装订册”布局：隐藏系统标题栏，左侧侧栏放文件树，编辑区上方一行顶栏放标签页和模式切换，大纲在编辑区右侧且默认隐藏；详见[界面与交互](ui.md)。 |
| 选中文字后的操作 | 不做浮动工具栏，正文不加自定义右键菜单；靠格式快捷键、输入标记字符包裹选区和默认关闭的固定格式工具栏，见[界面与交互](ui.md#选中文字后的操作)。 |
| 多个文件夹 | 单窗口多根目录：P0 只有一个根目录，切换前提醒；P1 允许添加多个根目录。不做多窗口，避免每个窗口多一个 WebKit 进程。 |
