# 文档工具

本文说明 Frontmatter 表单与导出。两者都处理当前 Markdown 文档的快照，不重建编辑器；命令来自统一注册表，可在命令面板执行或在编辑偏好中绑定键位。

## Frontmatter 表单

- “编辑 Frontmatter”（`document.frontmatter`）打开文档起始 YAML 元数据表单；没有元数据时，可添加标准 `---` 起止块。支持 `---` 或 `...` 结束标记，保留 BOM 与换行风格。
- 字段名为文字，值可选文字、数字、布尔值或 YAML；列表、嵌套对象和其他复杂值用 YAML 编辑。未知字段保留，注释、锚点和别名由 [yaml 的文档模型](https://eemeli.org/yaml/#documents)处理，不执行自定义标签或代码。
- 只有“应用修改”或 ⌘/Ctrl+Enter 才更新元数据，形成一个隔离的撤销步骤；取消、Esc 或未改动时不写正文。组合输入期间快捷操作归输入法。
- 来源文档、视图或文本变化会取消草稿；旧表单不能写入新文档。正文始终保留原字节，不通过渲染结果反向序列化。
- 已存在的普通字段通过 YAML CST 和源码位置局部修改，未改字段、注释、空白和分隔符保持原字节。明确编辑的复杂值可以规范化其自身格式；无法安全局部修改的根级 flow 结构增删、字段重排或特殊锚点/标签变更会提示使用源码，不整块重新排版。
- 表单处理最多 200 个字段、64 Ki 个 UTF-16 码元的 YAML。无效 YAML、非映射顶层、非文字字段名、缺少结束标记或超限时明确提示，用户可继续使用源码编辑；不能静默丢弃不认识的值。
- 闭合元数据在编辑器中保留源码，不当作正文标题、链接或大纲项；只读预览不把它当成正文渲染。未闭合的起始元数据在只读预览中按转义源码显示，避免吞掉后续内容。

## 导出与富文本

命令分别为“导出 HTML”（`document.export-html`）、“导出 PDF”（`document.export-pdf`）、“复制为富文本”（`document.copy-rich-text`），均要求活动标签是 Markdown。执行时读取当前编辑文本，包含尚未保存的内容，不强制保存源文件。

- HTML 复用正文预览的安全渲染，包含 GFM、语言高亮、公式、Mermaid 和 Callout。样式使用当前已解析主题、正文字体、字号、行距、宽度和受限 CSS；导出文件自行携带 CSS、KaTeX WOFF2、图表 SVG 与已授权本地图片，不依赖应用私有图片协议或 CDN。
- 远程图片不请求、不嵌入，以替代文字保留并提示；当前权限无法解析的图片同样提示。已经获得授权、但读取或内嵌失败的本地图片会使整次导出失败，不保存破图版本。单个资源最多 16 MiB，最终 HTML 最多 48 MiB。
- PDF 在独立、隐藏、临时会话的 WebView 内加载自包含 HTML，等待字体和图片就绪后调用 MyGo `Page.PrintToPDF`。A4 竖版、0.5 英寸边距、保留背景；打印样式允许代码换行、表头重复，并尽量避免拆分表格行、图片和图表。PDF 与富文本展开折叠 Callout 的正文；HTML 保留其初始展开语义。
- 富文本通过原生剪贴板的同一个 item 同时提供 `text/html` 与 `text/plain`，目标应用按自身能力选择。纯文本保留表格分隔，公式只保留一份文字表示，避免把 MathML 与可见排版重复拼接。
- 原生保存对话框只授权一次性目标 token，不接受正文传入任意写盘路径。取消、超时、准备失败和 PDF 生成失败不会发布目标文件；完成前源文档、路径、授权或视图失效会取消旧结果。准备与原生打印各有 30 秒上限，准备过程中可按 Esc 取消。
- 生成的 HTML 禁止文档脚本与外部资源；隐藏打印页另有强制 CSP，禁止导航与新窗口。导出不会修改源 Markdown 或其资源目录。

当前原生 PDF 验证限 macOS。MyGo/WebKit 的字体映射可能使个别图表字形在 PDF 文本提取中变成兼容字符；视觉渲染正常，不宣称所有字符都能逐字复制一致。Windows/Linux 的原生打印及剪贴板仍需各平台实机确认。
