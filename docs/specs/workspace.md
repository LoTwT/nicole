# 工作区与文件

概要：

- 工作区采用单窗口加标签页，不使用 MyGo 的 Documents API。
- 前端持有正在编辑的内容，Go 负责落盘，停止输入约 1 秒后保存。
- 工作区根是进程内可替换的状态；文件监听和后续的自定义协议在启动时注册，运行时读取当前根。
- 崩溃恢复依赖 `PathUserData` 下的未保存内容副本。
- 拖入和粘贴的图片存到 `assets/`，图片数据不经过 IPC。
- 搜索在 MVP 阶段直接扫描文件，将来改用 SQLite FTS5 的 trigram 分词。
- 文件监听使用 MyGo 的 `watch` 插件。
- 启动时窗口在光标所在的屏幕居中，尺寸沿用上次保存的大小。

## 工作区接口

Go 的 `Workspace` 服务通过 `mygo.Bind` 暴露，前端经 `src/services/workspace.ts` 调用。生成客户端在 `src/services/mygo.ts`，MyGo 调用只出现在 `src/services/` 和 Go 入口（见[依赖边界](../architecture.md#依赖边界)）。

| 方法 | 行为 |
|---|---|
| `ChooseFolder()` | 打开原生文件夹对话框。取消时返回 `canceled: true`，当前工作区不变；成功时切换工作区并返回根目录和文件列表。 |
| `ListFiles()` | 返回当前工作区的 Markdown 文件，规则见[列文件规则](#列文件规则)。没有打开工作区时返回错误。 |
| `ReadFile(path)` | 返回文件原始内容的字符串，不做换行或编码转换。 |
| `WriteFile(path, content)` | 原子替换文件，保证见[写入保证](#写入保证)。 |

工作区根保存在进程内的一个状态对象中，`ChooseFolder()` 只替换这个状态。后续要加的自定义协议在启动时注册，运行时读取当前根，换工作区不重新注册任何东西（见[文件监听](#文件监听)与[架构](../architecture.md#进程和模块结构)）。

## 列文件规则

- 递归遍历工作区，只列出普通文件；扩展名为 `.md`。扩展名比较不区分大小写。
- 不进入名字以 `.` 开头的目录，也不进入 `node_modules`；其他目录照常遍历。
- 不跟随符号链接：符号链接文件不列出，符号链接目录也不进入。
- 返回相对工作区的路径，统一用 `/` 分隔，并按字符串排序。
- 列表失败时返回错误，不返回部分结果。
- 名字以 `.` 开头的文件仍会列出，例如 `.draft.md`；只有隐藏目录被跳过。

## 路径守卫

`ReadFile` 和 `WriteFile` 的路径参数都是相对工作区的路径。以下情况一律拒绝：

- 空路径、`.`，或包含 `\`；无论当前平台是什么，`..\` 都按非法路径处理。
- 绝对路径，包括 `/...`、`C:\...` 和 `C:/...`；以盘符开头的路径在所有平台上都拒绝。
- 含 `.`、`..` 或空分段的路径；校验与 `fs.ValidPath` 一致。
- 解析符号链接（`filepath.EvalSymlinks`）后不在工作区内的路径。读取检查目标文件本身；写入检查目标文件，或新文件的父目录。
- 符号链接指向工作区外时读写都拒绝；指向工作区内时允许，写入落到链接目标，链接本身保留。

工作区根在打开时解析符号链接并保存为绝对路径。包含判断按路径分段（`filepath.Rel`）而不是字符串前缀，因此 `notes-other` 不会被当成 `notes` 的子目录。大小写不敏感的文件系统上，父目录路径必须使用磁盘上的实际大小写；不同大小写的路径按工作区外处理（fail closed）。前端只使用 `ListFiles()` 返回的路径，因此不受影响。

## 写入保证

- 读写都按字节处理：换行符、文件末尾是否有换行、UTF-8 BOM 都原样保留。
- CodeMirror 内部把换行统一成 `\n`；前端在加载文件时记下换行风格（LF、CRLF 或 CR），保存时按同一风格写回，所以使用一致换行风格的文件不会被整篇改写。同一文件混用多种换行时，会统一为加载时检测到的风格（CodeMirror 的限制）。
- 写入先在目标文件所在目录创建临时文件，写完、同步并关闭后再改名替换目标。
- 失败时目标文件保持原内容，临时文件被删除。
- 目标文件已存在时保留其权限位。
- 保存失败会返回错误；前端只显示“保存失败”，不自动重试。

## 窗口位置

- 启动时窗口在光标所在的显示器工作区居中，而不是恢复上次的位置。
- 尺寸沿用上次保存的尺寸；没有保存过时使用默认 `1100×780`。
- 尺寸超过当前显示器工作区时缩小到工作区大小。
- 状态仍保存在 `PathUserData/window-state.json` 的 `main` 下，格式与 MyGo 的默认存储一致；移动、缩放、最大化和关闭时的记录仍由 MyGo 完成。
- 实现使用 `Screen.CursorScreenPoint`、`Screen.DisplayNearestPoint` 和自定义 `WindowStateStore`；拿不到显示器信息时回退到 `Screen.PrimaryDisplay`。

## 工作区模式

只用一个窗口，用标签页切换文档。

**不用** MyGo 的 Documents API（见 [MyGo 参考](../references/mygo.md#documents-api)）：每多一个窗口就多一个 WebKit 页面进程，约多 40–50MB。内存预算见[性能](performance.md#预算)。

复用 MyGo 的文件关联和最近文档功能：双击 `.md` 文件时，打开它所在的文件夹作为工作区，并定位到这个文件。

## 保存

- **前端管正在编辑的内容，Go 管磁盘。**
- 停止输入约 1 秒后，把全文发给 Go 保存。文章很小，不需要增量同步。
- Go 先写临时文件，再改名覆盖目标文件，避免中途失败留下半个文件；保证见[写入保证](#写入保证)。
- 自动保存在三种编辑模式下都生效（见[编辑模式](editor-modes.md#所有模式共用的能力)）。
- 切换文件前会先保存当前文件，避免防抖期间切换导致丢失编辑。

## 崩溃恢复

Go 在 `PathUserData` 目录下保存未保存内容的副本，用于崩溃恢复。

## 图片

| 来源 | 做法 |
|---|---|
| 拖入文件 | 用 `onFileDrop` 拿到文件路径，由 Go 复制。 |
| 粘贴 | 由 Go 直接读取系统剪贴板。 |

- 图片存到工作区的 `assets/` 目录。
- 在 Markdown 中插入相对路径。
- 图片数据都不经过 IPC，因为 MyGo 会把 `[]byte` 转成 base64 再传输。
- 显示图片时，用 `mygo.Protocol.Handle` 注册自定义协议；协议的范围和访问限制见[安全](../architecture.md#安全)。

## 搜索

- MVP 阶段由 Go 直接扫描文件，通过 Channel 流式返回结果（见 [IPC 用法](../architecture.md#ipc-用法)）。
- 文件多了以后再上 SQLite FTS5，使用 **trigram 分词**；默认分词器切不开中文。

## 文件监听

使用 MyGo 的 `watch` 插件监听工作区变化。插件的能力和默认参数见 [MyGo 参考](../references/mygo.md#插件)。

- 应用启动时用 `watch.New` 注册插件，不写死根目录；根名固定为 `workspace`。
- 插件通过 `Options.Resolve` 在每次 watch 时读取当前工作区根，因此换工作区只替换进程内状态，不重新注册插件或协议。
- 工作区根按[列文件规则](#列文件规则)的同一套规则递归监听：跳过隐藏目录和 `node_modules`。
- 变更通过插件的 Channel 交给前端。前端如何响应外部修改由 UI-2a 接入（`@mygo-plugins/watch`），本阶段只保证 Go 端的授权、忽略规则和状态切换可用。
