# 工作区与文件

概要：

- 工作区采用单窗口加标签页，不使用 MyGo 的 Documents API。
- 前端持有正在编辑的内容，Go 负责落盘，停止输入约 1 秒后保存。
- 工作区根是进程内可替换的状态；文件监听和后续的自定义协议在启动时注册，运行时读取当前根。
- 崩溃恢复依赖 `PathUserData` 下的未保存内容副本。
- 拖入和粘贴的图片存到 `assets/`，图片数据不经过 IPC。
- 搜索在 MVP 阶段直接扫描文件，将来改用 SQLite FTS5 的 trigram 分词。
- 文件监听使用 MyGo 的 `watch` 插件。
- 启动时窗口在光标所在的屏幕居中，尺寸沿用上次保存的大小。

## 工作区接口

Go 的 `Workspace` 服务通过 `mygo.Bind` 暴露，前端经 `src/services/workspace.ts` 调用。生成客户端在 `src/services/mygo.ts`，MyGo 调用只出现在 `src/services/` 和 Go 入口（见[依赖边界](../architecture.md#依赖边界)）。

| 方法 | 行为 |
|---|---|
| `ChooseFolder()` | 打开原生文件夹对话框。取消时返回 `canceled: true`，当前工作区不变；成功时切换工作区并返回根目录、文件列表、`generation` 和监听根名 `watchRoot`。 |
| `ListFiles()` | 返回当前工作区的 Markdown 文件，规则见[列文件规则](#列文件规则)。没有打开工作区时返回错误。 |
| `ReadFile(path)` | 返回 Markdown 文件原始内容的字符串，不做换行或编码转换。 |
| `WriteFile(path, content, generation)` | 原子替换文件；`generation` 与当前工作区不一致时拒绝。保证见[写入保证](#写入保证)。 |
| `ConfirmDiscard()` | 切换文件或文件夹前，前端在保存失败或换行风格混合时询问用户是否放弃更改。多标签页界面实现后，前端改用页面对话框，不再调用它（见[界面与交互](ui.md#切换文件夹)）。 |
| `FinishClose(token, saved)` | 回答一次关窗请求；`token` 标识该次请求。`saved` 为 `true` 时关窗，`false` 时 Go 弹出确认框，用户明确选择放弃后才关窗。过期请求的回答会被忽略。 |

工作区根保存在进程内的一个状态对象中，`ChooseFolder()` 只替换这个状态并递增 `generation`。后续要加的自定义协议在启动时注册，运行时读取当前根，换工作区不重新注册任何东西（见[文件监听](#文件监听)与[架构](../architecture.md#进程和模块结构)）。

## 列文件规则

- 递归遍历工作区，只列出普通文件；扩展名为 `.md`。扩展名比较不区分大小写。
- 不进入名字以 `.` 开头的目录，也不进入 `node_modules`；其他目录照常遍历。
- 不跟随符号链接：符号链接文件不列出，符号链接目录也不进入。
- 返回相对工作区的路径，统一用 `/` 分隔，并按字符串排序。
- 列表失败时返回错误，不返回部分结果。
- 名字以 `.` 开头的文件仍会列出，例如 `.draft.md`；只有隐藏目录被跳过。

## 路径守卫

`ReadFile` 和 `WriteFile` 的路径参数都是相对工作区的路径，而且只能指向符合[列文件规则](#列文件规则)的 Markdown 文件：扩展名 `.md`、不在隐藏目录或 `node_modules` 里、最终是普通文件。图片写入由 `Assets` 单独提供，不放开这两个方法。

- 空路径、`.`，或包含 `\` 或 `:`；无论当前平台是什么，`..\` 都按非法路径处理。
- 绝对路径，包括 `/...`、`C:\...` 和 `C:/...`；以盘符开头的路径在所有平台上都拒绝。
- 含 `.`、`..` 或空分段的路径；校验同时使用 `fs.ValidPath` 和 `filepath.IsLocal`。
- 解析符号链接（`filepath.EvalSymlinks`）后不在工作区内的路径。读取检查目标文件本身；写入检查目标文件，或新文件的父目录。
- 符号链接指向工作区外、隐藏目录或 `node_modules` 时读写都拒绝；指向工作区内可见 Markdown 文件时允许，写入落到链接目标。
- 悬空符号链接不会写入，也不会被替换成普通文件。

实际的文件打开、读取、创建、改名、删除和 chmod 都通过 `os.OpenRoot` / `os.Root` 完成，保证操作不越出工作区根；`filepath.EvalSymlinks` 只用于在操作前确定并检查目标。仍有两个限制：检查和实际打开之间路径组件可能被替换，从而绕过隐藏目录或 `node_modules` 规则；工作区根目录本身被替换时，后续操作会落到新目录上。

工作区根在打开时解析符号链接并保存为绝对路径。包含判断按路径分段（`filepath.Rel`）而不是字符串前缀，因此 `notes-other` 不会被当成 `notes` 的子目录。大小写不敏感的文件系统上，父目录路径必须使用磁盘上的实际大小写；不同大小写的路径按工作区外处理（fail closed）。前端只使用 `ListFiles()` 返回的路径，因此不受影响。

## 写入保证

- 读写都按字节处理：换行符、文件末尾是否有换行、UTF-8 BOM 都原样保留。
- CodeMirror 内部把换行统一成 `\n`；前端在加载文件时统计换行风格（LF、CRLF 或 CR），保存时按同一风格写回，所以使用一致换行风格的文件不会被整篇改写。
- 同一文件混用多种换行时，前端标记为“换行风格混合”，不自动保存，并保留待保存内容；状态栏和横幅的显示见[界面与交互](ui.md#保存状态)。切换文件、切换文件夹或关窗时，用户必须在确认框中选择放弃更改；取消则保留当前编辑（这是当前单编辑器界面的行为，多标签页界面中切换文件不需要确认，见[界面与交互](ui.md#切换文件夹)）。文本撤销回读入时的内容后，待保存内容会被清空，不再阻止切换或关闭。
- 写入先在目标文件所在目录创建临时文件，写完、同步并关闭后再改名替换目标。
- 失败时目标文件保持原内容，临时文件被删除。
- 新文件使用 `0666` 并遵循进程 umask；已有文件保留权限位。目标文件没有写权限时拒绝保存，并返回明确错误。
- 改名在 Windows 上遇到文件被占用会重试；改名后对所在目录做 fsync（Windows 跳过）。
- 打开工作区时清理本应用遗留的临时文件，只删除名字匹配 `.nicole-<16 位十六进制>.tmp` 且修改时间早于 10 分钟的文件；最近的文件可能属于另一个仍在写入的实例，不删除。
- 保存失败会返回错误；前端只显示“保存失败”，不自动重试。

## 窗口位置

- 启动时窗口在光标所在的显示器工作区居中，而不是恢复上次的位置。
- 尺寸沿用上次保存的尺寸；没有保存过时使用默认 `1100×780`。
- 尺寸超过当前显示器工作区时缩小到工作区大小。
- 状态仍保存在 `PathUserData/window-state.json` 的 `main` 下，格式与 MyGo 的默认存储一致；移动、缩放、最大化和关闭时的记录仍由 MyGo 完成。
- 实现使用 `Screen.CursorScreenPoint`、`Screen.DisplayNearestPoint` 和自定义 `WindowStateStore`；拿不到显示器信息时回退到 `Screen.PrimaryDisplay`。

## 工作区模式

只用一个窗口，用标签页切换文档。

**不用** MyGo 的 Documents API（见 [MyGo 参考](../references/mygo.md#documents-api)）：每多一个窗口就多一个 WebKit 页面进程，约多 40–50MB。内存预算见[性能](performance.md#预算)。

复用 MyGo 的文件关联和最近文档功能。打开一个 `.md` 文件时，按它是否位于已打开或最近用过的文件夹中分别处理，规则见[界面与交互](ui.md#打开工作区之外的文件)。

界面按“单窗口多根目录”设计：P0 只有一个根目录，打开另一个文件夹时替换当前根目录；P1 允许同时添加多个根目录，仍在同一个窗口里，不增加 WebKit 进程（见[界面与交互](ui.md#根目录)）。

## 保存

- **前端管正在编辑的内容，Go 管磁盘。**
- 停止输入约 1 秒后，把全文发给 Go 保存。文章很小，不需要增量同步。
- Go 先写临时文件，再改名覆盖目标文件，避免中途失败留下半个文件；保证见[写入保证](#写入保证)。
- 自动保存在三种编辑模式下都生效（见[编辑模式](editor-modes.md#所有模式共用的能力)）。
- 选择文件前先保存当前文件；保存失败或换行风格混合时，前端调用 `ConfirmDiscard()` 让用户选择“放弃更改并继续”或“取消”。取消会恢复选择并保留编辑，放弃则把编辑器恢复到读入内容后继续。打开文件夹前也先保存：`ChooseFolder()` 会切换 Go 端的根，所以保存必须发生在它之前。打开文件夹成功后不保留旧文件的编辑器，只显示选择文件的占位。以上是当前单编辑器界面的行为；多标签页界面中，切换文件只是切换标签页，切换文件夹前的确认、按根目录恢复标签页和占位状态见[界面与交互](ui.md#切换文件夹)。
- 待保存内容绑定键入时的 `path`、`generation` 和文本；写入与失败恢复都使用这组值，路径已变化时不恢复，避免旧文件的内容写进新文件。读取下一个文件期间编辑器仍可输入；读取完成后先保存这段时间产生的编辑，失败或用户取消则中止切换。
- 文件读取以最新一次选择为准：新的选择会作废未完成的读取；打开文件夹只在用户选中并切换到新工作区后作废进行中的读取，取消对话框不会。旧结果返回后丢弃，不加载、不改变当前状态，旧读取的错误也不显示。
- 保存请求带工作区的 `generation`。切换期间的旧写入会被 Go 拒绝，不会落到新工作区。
- 关窗时 Go 先阻止关闭，通过携带 `token` 的 `workspace:save-before-close` 事件让前端保存。保存成功后前端调用 `FinishClose(token, true)` 关闭窗口；保存失败或混合换行时调用 `FinishClose(token, false)`，由 Go 弹出“仍然关闭 / 取消”确认框，只有用户明确选择仍然关闭才销毁窗口。重复关窗沿用第一次请求；页面无响应时最多等待 5 秒后关窗，超时之后到达的回答因 token 过期而无效。前端还在 `beforeunload`、`pagehide` 和页面隐藏时尝试立即保存，这段时间内的极端情况仍需崩溃恢复兜底。

## 崩溃恢复

Go 在 `PathUserData` 目录下保存未保存内容的副本，用于崩溃恢复。

## 图片

| 来源 | 做法 |
|---|---|
| 拖入文件 | 编辑器拦截编辑区里的文件拖放；窗口的 `Window.OnFileDrop` 把路径保存在 Go，并向页面发一次性 token 和落点坐标。页面先用 `EditorHandle.containsPoint` 确认落点在编辑区内，再用坐标创建插入位置，`Assets.ImportImages(docPath, generation, dropToken)` 按 token 取路径并复制图片。token 约 10 秒过期，只能使用一次。 |
| 粘贴 | 编辑器检测到剪贴板里有图片时阻止默认粘贴；`Assets.PasteImage` 由 Go 先读剪贴板里的本地文件列表。列表非空时只导入其中的图片文件，没有图片就返回“剪贴板没有图片”，不再回退读位图，避免把文件图标当图片插入；列表为空时才读取 PNG 位图。 |

保存：

- 图片存到**工作区根目录**的 `assets/`，不是当前文件旁边的目录。目录不存在时自动创建；`assets` 是符号链接或普通文件时拒绝写入。已有目录的权限不变，新文件使用 `0666` 并受 umask 约束。
- 文件名：
  - 粘贴位图：`image-YYYYMMDD-HHMMSS.png`，时间为本地时间。
  - 拖入或粘贴文件：原文件名去掉扩展名，保留 Unicode；空格和 `/`、`\`、`:`、`*`、`?`、`"`、`<`、`>`、`|` 换成 `-`，首尾的 `.`、空格和 `-` 去掉，最多 60 个字符。扩展名统一小写。
  - 重名时在扩展名前依次加 `-2`、`-3`，直到找到未占用的名字。
- 插入相对当前文件的 Markdown 图片语法，替代文本为空，例如 `![](../assets/image-20261031-153000.png)`；路径按段做 URL 转义。相对路径以调用方传入的 `docPath` 为基准，即使该文档是工作区内的符号链接也不改用链接目标的目录。从非空行的开头插入时，图片单独占一行（文本后补一个换行），其他位置直接插在光标处。一次粘贴或一次拖入（可含多张）在编辑器中是一个撤销步。
- 剪贴板位图只接受 PNG；macOS 的 TIFF 等格式由 MyGo 转成 PNG。粘贴和拖入都先按扩展名筛选，再检查字节确实是图片；SVG 去掉开头的 BOM、XML 声明、注释和 DOCTYPE 后，第一个元素必须是 `<svg`。没有图片扩展名的文件直接忽略，不插入链接。源文件是符号链接或非常规文件时拒绝，不跟随链接读取。
- 一次拖入多张图片时，先读完并校验全部文件，全部通过后才开始写入；写入失败时删除本次已经写入的文件并返回错误，不留下半批图片。粘贴文件列表出现同类错误时同样不写任何文件。
- 写入先在同一目录创建临时文件，再用**不覆盖已有文件**的硬链接发布到目标名；目标已存在时换下一个后缀，绝不替换已有图片。失败时目标文件不存在，临时文件被删除，权限规则与[写入保证](#写入保证)相同。文件系统不支持硬链接时（例如 exFAT/FAT、部分 SMB/NFS 挂载），改用 `O_EXCL` 直接创建目标文件并写入；这仍不会覆盖已有文件，但目标名从写入开始就可见，读者可能看到尚未写完的内容，因此没有“先写临时文件再发布”的原子性，写入失败时会删除该目标文件。
- 图片数据不经过 IPC：Go 只返回保存后的相对路径和 Markdown；页面只传文档路径、generation 和 drop token。
- 中文输入法组合期间收到插入请求时先排队，组合结束后再插入；编辑器用插入凭据（ticket）持续映射位置，因此不会打断候选框，也不会因等待期间的编辑而落到错误位置。
- 手测项：在 Finder 里复制一张 jpg 后按 ⌘V，应导入原文件并插入相对路径，而不是粘贴图标或位图；从 Finder 把图片拖进编辑区，应保存到 `assets/` 并在落点插入。真实剪贴板和拖放不进入自动化测试。

显示：

- 编辑器把图片 URL 交给 `resolveImage`。相对路径按当前文件所在目录解析，开头的 `/` 表示工作区根；结果转换成 `nicole-image://localhost/<generation>/<工作区相对路径>`。
- `http`、`https` 和 `data:image/*` 原样保留。其他绝对 URL、协议相对 URL（`//`）、越出工作区、隐藏目录、`node_modules`、不支持的扩展名，以及含 `?` 或 `#` 的本地路径都返回 null，编辑器保留 Markdown 原文。
- 协议只提供当前工作区里的图片，扩展名清单为 `.png`、`.jpg`、`.jpeg`、`.gif`、`.webp`、`.svg`，比较不区分大小写。路径经与[路径守卫](#路径守卫)相同的检查和 `os.Root` 打开；越界、隐藏目录、`node_modules`、符号链接逃逸、非图片扩展名和旧 generation 都返回 404。响应带正确的 `Content-Type`；安全约束见[架构](../architecture.md#安全)。

## 搜索

- MVP 阶段由 Go 直接扫描文件，通过 Channel 流式返回结果（见 [IPC 用法](../architecture.md#ipc-用法)）。
- 文件多了以后再上 SQLite FTS5，使用 **trigram 分词**；默认分词器切不开中文。

## 文件监听

使用 MyGo 的 `watch` 插件监听工作区变化。插件的能力和默认参数见 [MyGo 参考](../references/mygo.md#插件)。

- 应用启动时用 `watch.New` 注册插件，不写死根目录；每次打开文件夹返回一个带 `generation` 的根名，例如 `workspace-3`。
- 插件通过 `Options.Resolve` 在每次 watch 时读取当前工作区根；`Resolve` 只接受当前这一代的根名，旧根名不能再次授权。
- 换工作区只替换进程内状态，不重新注册插件或协议。前端必须先关闭旧 watcher，再用新的 `watchRoot` 开始监听。
- 工作区根按[列文件规则](#列文件规则)的同一套规则递归监听：跳过隐藏目录、`node_modules` 和名字匹配 `.nicole-<16 位十六进制>.tmp` 的本应用临时文件。
- 变更通过插件的 Channel 交给前端。前端如何响应外部修改由 UI-2a 接入（`@mygo-plugins/watch`），本阶段只保证 Go 端的授权、忽略规则和状态切换可用。
- 文件树显示所有文件（见[界面与交互](ui.md#文件树)），需要非 `.md` 文件的新增、删除和改名；监听是否上报这些变化，由 UI-2a 确认后写进本节。隐藏目录和 `node_modules` 仍不监听，文件树在展开这些目录时重新读取。
