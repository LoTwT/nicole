# 编辑模式

概要：

- 提供实时预览、沉浸、源码三种模式，共用同一个 CodeMirror 6 内核。
- 三种模式都必须具备相同的写作能力；沉浸模式另有链接编辑、格式快捷键、浮动工具栏和边界输入规则。
- 拼音输入过程中不能重建当前行的渲染，组合结束后再重建（见[中文输入法](#中文输入法)）。
- 正式版按当前元素展开原文，而不是像演示那样整行展开。

## 三种模式

三种模式都必须支持，用户可以随时切换。

| 模式 | 效果 |
|---|---|
| 实时预览（默认） | 光标所在的地方显示 Markdown 原文，其他地方渲染。类似 Obsidian 的 Live Preview。 |
| 沉浸 | 符号永远隐藏，类似 Typora；光标自动跳过隐藏的符号（atomic ranges）。 |
| 源码 | 一直显示原文。 |

## 单一编辑器内核

只用一个编辑器内核，三种模式只是显示方式不同，通过 CodeMirror 6 的 Compartment 切换。

**不要**另外引入 ProseMirror 那类所见即所得引擎：它保存时要把富文本转回 Markdown，会改写源码；而且每个功能都得做两遍。这与[源码保持干净](product.md#定位)的约束冲突。

渲染基于语法树和 decorations/widgets，语法解析使用 `@codemirror/lang-markdown` 的 GFM 支持（见[技术选型](../architecture.md#技术选型)）。

## 所有模式共用的能力

以下功能在三种模式下都必须能用：

- Slash 命令（见[Slash 命令](slash-commands.md)）
- 快捷键
- 粘贴图片（见[工作区与文件](workspace.md#图片)）
- 大纲
- 自动保存（见[工作区与文件](workspace.md#保存)）

## 沉浸模式的额外工作

沉浸模式隐藏了所有标记，因此需要额外处理：

- 用弹出框编辑链接和图片，因为看不到 URL。
- 格式快捷键用于切换格式（如 ⌘B 切换加粗）。
- 浮动工具栏。
- 边界输入规则，例如在加粗文字末尾继续输入时，新输入的字是否算加粗。

## 中文输入法

中文输入法在 macOS WKWebView 里的表现是项目的最大技术风险（见[主要风险](../architecture.md#主要风险)）。约束是：**拼音输入过程中不能重建当前行的渲染**。这会直接影响实时预览和沉浸模式隐藏符号的逻辑。

实时预览和沉浸模式共用 `src/editor/index.ts` 中的 `preview()`，实现方式：

- 组合输入期间（`view.compositionStarted` 为真）跳过 decorations 重建，只用 `DecorationSet.map` 把已有 decorations 随事务移到新位置，语法树不再重新遍历。
- `composing` 要到第一次组合文本变化时才为真；`compositionStarted` 还覆盖了从 `compositionstart` 到第一次变化之间的更新，在这段时间里重建同样会让 WKWebView 丢掉候选框。
- 跳过重建时记下“渲染已过期”，组合结束后的第一次更新重新构建 decorations。这样即使那次更新只有空事务（例如用 Backspace 撤销整个组合，文档回到原样）也会重新渲染。
- 映射而不是直接保留原位置，是因为组合期间文档仍在变化；映射后 widget 和 decorations 的位置始终有效，但不会重新判断当前行、隐藏符号或任务框。

### 手测清单

真实中文输入法的手感只能在 WebView 里手测，自动化测试覆盖不到。macOS（WKWebView）按下面逐项确认；Windows WebView2 和 Linux（WebKitGTK）待实测。

| 场景 | 操作 | 期望 |
|---|---|---|
| 标题行 | 光标在标题行，在标题文字中间输入拼音 | 组合期间 `#` 的显示状态、标题字号和行高都不变，候选框不消失 |
| 加粗内部 | 光标在 `**加粗**` 中间输入拼音 | `**` 在实时预览和沉浸模式下保持原来的显示状态，粗体不闪烁；上屏的文字仍是加粗 |
| 列表项 | 光标在 `- 项目` 中输入拼音 | 列表符号不重建、不闪烁 |
| 任务项 | 光标在 `- [ ] 任务` 中输入拼音 | 任务框 DOM 不重建，勾选状态不变，任务文字正常更新 |
| 沉浸模式隐藏符号的边界 | 光标停在隐藏的 `#`、`**` 或列表符号边界处输入拼音 | 符号保持隐藏，光标不跳进隐藏区域；组合结束后按新位置重新隐藏 |
| 切换候选词 | 组合期间用数字键、方向键或翻页键切换候选 | 候选框不消失，行内容和光标位置不跳动 |
| Backspace 撤销组合 | 组合期间连续按 Backspace 删除拼音 | 文字逐步还原，候选框不消失；组合结束、文档回到原样后当前行渲染正确 |
| Esc 取消组合 | 组合期间按 Esc | 拼音消失，文档回到原样，当前行渲染正确；之后再输入或移动光标，渲染仍然正确 |
| 组合期间切换窗口或失焦 | 组合期间点击其他窗口或让编辑器失焦 | 组合结束后当前行渲染能恢复，重新聚焦后继续输入正常 |
| 组合结束后的渲染 | 候选词上屏 | 当前行按最新语法重新渲染：标题、加粗、列表、任务框和隐藏符号都正确 |

## 渲染粒度

演示实现是**整行展开**：光标在某一行时，这一行全部显示原文。正式版应细到**只展开光标所在的那个元素**，例如光标在加粗文本里时只露出这对 `**`，而不是让整行的语法标记都出现。

## 当前实现

`src/editor/index.ts` 已从交接附件中的 `main.ts`（2026-10 验证，不纳入仓库）移植，接口见[架构](../architecture.md#依赖边界)。当前仍保持演示的**整行展开**，后续再细到元素。

- `preview(reveal)` 生成一个 `ViewPlugin`；文档、视口或选区变化时，在可见范围内重建 decorations。组合输入期间跳过重建，只做位置映射，见[中文输入法](#中文输入法)。
- 遍历语法树：隐藏 `HeaderMark`、`EmphasisMark`、`CodeMark`、`StrikethroughMark`、`QuoteMark`、任务项的列表符号和链接的 URL；把列表符号、任务框、图片、分割线替换成 widget；标题和引用用行级 decoration。
- 任务框自绘：`appearance: none` 的 `<input type="checkbox">` 覆盖在容器上，负责点击和键盘操作；外框、背景和勾选标记都由容器上的 CSS 绘制，读取 `--nicole-checkbox-*` 变量，回退见 `src/editor/index.ts` 的 `editorTheme`，因此亮暗切换不需要重建编辑器。任务框 widget 的 `eq` 只比较勾选状态，`updateDOM` 原地更新勾选样式以保留焦点；点击时用 `view.posAtDOM` 和文档内容取当前位置与状态，避免在前面输入文字时重建任务框。
- 沉浸模式额外注册 `EditorView.atomicRanges`，让光标跳过隐藏的符号。
- 用 ⌘B（CodeMirror 的 `Mod-b`）切换加粗；光标折叠时插入一对空标记，选中文本时在两侧加 `**`。
- 三种模式的扩展通过同一个 Compartment 切换，`EditorView` 不重建。
- 编辑器主题只读 CSS 变量，亮暗切换只改 class（见[主题与字体](theming.md#编辑器主题)）。

尚未实现：展开粒度细化到元素、链接/图片弹出编辑、slash 命令、浮动工具栏和边界输入规则。
