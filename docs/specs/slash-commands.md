# Slash 命令

概要：

- 在行首或空格后输入 `/`（中文输入法下为 `、`）触发，可按编辑模式单独开关。
- 内置命令覆盖标题、列表、代码块、表格、公式、媒体等常见插入操作。
- 用户模板放在 `.nicole/snippets/*.md`，支持 `{{date}}`、`{{cursor}}` 等变量。
- 命令只有一个注册表，slash 菜单、快捷键、命令面板、格式工具栏和右键菜单都从它读取。
- Slash 命令只插入 Markdown 文本，因此与编辑模式无关。

## 触发与开关

- 只在行首或空格后输入 `/` 才触发；中文输入法在同样的位置输出的 `、` 也触发。
- 触发位置在围栏代码块、缩进代码块、行内代码、frontmatter 或 HTML 块内时不触发，与[界面与交互](ui.md#选中文字后的操作)包裹规则第 4 条的排除范围一致。
- 选中文字后输入 `/` 时替换选区，不触发菜单。
- 查询中出现空白（包括紧跟触发符的空格）时关闭菜单，保留已经输入的 `/` 或 `、` 和查询文字。输入法组合期间先等待组合结束再判断。
- 可以在设置里按编辑模式单独开关（实时预览、沉浸、源码）。

## 内置命令

| 类别 | 命令 |
|---|---|
| 结构 | 标题 1–3、引用、分割线 |
| 列表 | 各类列表、任务项 |
| 代码 | 代码块（插入后再选语言） |
| 内容块 | 表格、callout、公式、Mermaid |
| 媒体与链接 | 图片、链接、日期、链接到文件 |

当前实现已经登记表中的全部命令。图片和“链接到文件”需要文件列表或文件选择器的完整交互，现在先插入 Markdown 模板（`![](图片路径)`、`[文件名](相对路径)`）并选中待替换的文字；链接命令同样先插入 `[链接文字](https://)` 模板。代码块插入后光标停在开头的围栏后，可以直接输入语言名称，还没有单独的语言选择器。

## 用户模板

用户自定义模板放在当前已打开根目录的 `.nicole/snippets/`。模板只读，不会自动打开为编辑标签，也不会写回模板文件；目录不存在时不创建，内置命令照常可用。

- 只读取这一级目录，不递归；候选是扩展名 `.md` 的目录项，扩展名比较不区分大小写，只有普通文件会被读取，内容按普通 UTF-8 文本处理。开头 BOM 和 CRLF/CR 在载入时归一化，编辑器内部使用 LF。
- 启动时不扫描目录。第一次打开 slash 菜单或命令面板时才调用 `Workspace.ListSnippets(generation)`；之后每次重新打开都会刷新目录快照。只保留当前根的一个有界快照，不新增 watcher、索引或数据库。
- 首次读取完成前，如果查询暂时只可能匹配模板，slash 菜单显示“正在读取用户模板”并保持打开，不提前按无匹配关闭；读取结束仍无匹配时才关闭并保留已输入文字。加载期间文字输入照常，Esc 随时关闭；没有可执行项时 Enter 按普通输入行为处理（包括换行）并关闭菜单，不执行状态提示行。命令面板在命令模式、没有可显示项时显示同一读取状态。
- 请求只带 `generation`，页面不能传目录或任意路径。Go 只读取当前根固定的 `.nicole/snippets/`；不放宽文件树、搜索、`ReadFile`、隐藏目录、`node_modules` 或单文件标签页的父目录规则。
- 上限为最多 100 个候选 `.md` 文件、单个文件 64 KiB、有效正文合计 1 MiB。目录数量或总量超限时整个用户目录不加载，并显示具体原因；单文件是符号链接、不是普通文件、读取失败、非法 UTF-8 或过大时只跳过该文件，并在提示中写出文件名。权限不足显示普通用户能理解的提示，内置命令仍可用。
- 根目录切换或关闭时立即清空已加载的命令和正文；迟到的读取结果不会进入新的根、新的菜单或旧的编辑器。模板文件在菜单打开期间发生变化时，不会热替换当前菜单，下一次打开命令界面才使用新快照。
- 每个模板都是普通 `CommandDefinition`，id 为 `snippet:<文件名>`，有独立命名空间，不会覆盖内置 id；标签取文件名去掉扩展名。slash 菜单和命令面板共用现有拼音、首字母、英文别名和最近使用排序，不新增快捷键、工具栏模板按钮或模板管理界面。
- 执行时替换当前选区，并与 slash 触发符、查询一起构成一个撤销步；自动保存仍然写入当前文档。`{{date}}` 换成执行当天的本地 `YYYY-MM-DD`；所有 `{{cursor}}` 会被删除，第一个位置成为完成后的光标，没有标记时光标落在插入文本末尾；其他 `{{...}}` 保持普通文字，绝不执行代码。
- 加载期间不打断中文输入法：slash 菜单不会在组合期间重排或处理按键，命令面板的异步列表更新不抢焦点，也不执行组合中的 Enter。

`.nicole/` 作为模板和工作区配置的统一目录，这一决定见[产品定位与范围](product.md#已定决策)。RPC、目录检查和读取安全见[工作区与文件](workspace.md#用户模板目录)。

## 搜索与排序

- 支持拼音模糊搜索，使用 `pinyin-pro`；第一次打开 slash 菜单时才动态加载，不进入空载内存。
- 匹配命令标题、标签拼音、拼音首字母和注册表里的英文别名。
- 最近用过的命令排在前面；记录保存在 WebView 的 `localStorage`（键 `nicole:commands:recent`），不写进工作区，最多保留 8 条。
- 命令面板文件模式的最近文件按根目录保存，位置和上限见[标签页存储](workspace.md#标签页存储)；它和命令的最近记录互不共用。
- 可以全程用键盘操作。

## 命令注册表

命令注册表只有一份，包含以下字段：

| 字段 | 用途 |
|---|---|
| id | 命令标识 |
| 标题 | 菜单中显示的名称 |
| 拼音关键词 | 拼音模糊搜索的匹配文本；标签本身的拼音由 `pinyin-pro` 在搜索时生成，这里补充首字母和英文别名 |
| 快捷键 | 命令对应的键盘操作，可以有多个键位，每个键位可以按平台分别给出（对应 CodeMirror `KeyBinding` 的 `key`、`mac`、`win`、`linux`）；默认键位见[界面与交互](ui.md#快捷键) |
| 图标与分组 | 供以后的格式工具栏使用；分组为行内、段落、内容块、插入类或应用类 |
| 作用域与菜单 | `scope` 为 `editor`、`app` 或 `file-tree`：编辑器命令从上下文读取 `EditorView`，应用命令由 `App.vue` 分发，文件树命令只在文件树有焦点时执行并从上下文取焦点节点；`inSlashMenu` 决定是否出现在 slash 菜单 |
| 是否可用 | `available` 默认为真；未实现功能的命令以 `available: false` 登记占位，快捷键仍可显示，但按键不执行命令，也不阻止默认行为（与未匹配的按键相同），slash 菜单和命令面板也不列出 |
| 状态要求 | `requiresWorkspace` 需要打开的根目录；`requiresOpenTab` 需要至少一个打开的标签页；`requiresActiveMarkdown` 需要活动标签页是 Markdown 文件；`requiresMultipleTabs` 需要至少两个打开的标签页；`requiresClosedTab` 需要关闭历史非空。未满足时命令不执行，也不显示在命令面板。有快捷键时，只有在应用快捷键生效的状态下（未处于输入法组合、焦点不在文本输入框、没有页面对话框或恢复对话框、命令面板未打开）且状态满足要求，按键才会被应用吞掉并阻止默认行为；状态不满足时也不执行命令，但仍阻止默认行为以免触发 WebView 或系统默认动作。其他状态与未匹配的按键相同。原生命令分发和命令面板的执行请求也由同一检查拦截；命令本身的 `run` 仍要检查上下文 |
| 执行函数 | 实际插入文本或执行操作；接收命令上下文，编辑器命令从中读取当前 `EditorView`，应用和文件树命令从中读取动作与焦点节点 |

Slash 菜单、快捷键、命令面板、格式工具栏和右键菜单都从这一份注册表读取，命令只注册一次。它们在界面上的位置和行为见[界面与交互](ui.md)。

应用命令当前的状态要求：`app.new-file`、`nav.search`、`nav.toggle-sidebar`、`app.close-workspace`、`app.collapse-folders`、`app.reveal-workspace` 和 `tab.reopen` 需要工作区；`tab.close` 需要打开的标签页；`app.save` 和 `nav.toggle-outline` 需要活动标签页是 Markdown 文件；`tab.next`、`tab.previous` 需要至少两个打开的标签页；`tab.reopen` 还需要关闭历史非空。关闭历史只记录工作区标签页，单文件标签页关闭后不进入历史。

## 与编辑模式的关系

Slash 命令的作用只是插入 Markdown 文本，所以和编辑模式无关，三种模式都能使用（除非在设置中关闭）。插入之后的编辑体验才与模式有关，例如表格组件在沉浸模式下的交互，见[编辑模式](editor-modes.md)。

## 当前实现（PR7a、PR7b-1、PR7b-2、PR8、PR10）

- 注册表在 `src/commands/registry.ts`，命令定义和格式、插入、应用与文件树命令都在 `src/commands/`；键位显示函数也在这里，slash 菜单、`KeyHint`、悬停提示和右键菜单共用同一份转换结果。
- 编辑器命令由 `createEditor` 统一注册为 CodeMirror keymap，并使用 `Prec.highest` 覆盖 `basicSetup` 的同名键位（例如 ⌘I）。应用命令由 `App.vue` 在窗口 `keydown` 捕获阶段分发，因此注册表键位先于 CodeMirror 的编辑器键位，例如 Windows 的 Ctrl+Shift+L 切大纲而不是选中相同文字；文件树命令只在文件树有焦点时由 `FileTree.vue` 分发；两者都使用 `src/commands/keybinding.ts` 的匹配器，不在组件里另写键位。
- 匹配器先按字符精确匹配全部命令；只有字符没有命中、事件带命令修饰键时，才进入物理键回退。回退使用 `event.code` 和 `keyCode` 表，支持 ⇧⌘[ / ⇧⌘] 在 US 布局报告 `{`/`}`、非 US 布局和 AZERTY 数字行；但事件已产生单个 ASCII 字符时不会按物理位置推出字母，避免 AZERTY ⌘Z、Dvorak ⌘, / ⌘B 误触其他命令。非 ASCII 输入（例如西里尔字母）仍可按物理位置匹配。Windows 和 Linux 的 Ctrl+Alt 不会被当成 Ctrl 快捷键。
- `available: false` 的占位命令（设置）保留键位以便界面显示，但匹配器跳过它们；slash 菜单和命令面板也只列出可用命令。大纲和全文搜索已启用，分别需要活动 Markdown 文件和工作区。
- slash 菜单的触发、查询、最近使用和按键归属在 `src/editor/slash.ts`，渲染和定位在 `src/components/SlashMenu.vue`。菜单宽 260px、最多 8 项，锚定光标下方并在空间不足时翻到上方，窗口内保留 8px。
- 执行命令时删除触发字符和查询后运行命令，删除查询和执行命令合并为一个撤销步；Esc、光标离开、出现空白和没有匹配项都只关闭菜单，不删除正文。组合输入期间 Enter、↑、↓、Esc 交给输入法，空白或无匹配也要等组合结束后再关闭。代码块、frontmatter 和 HTML 块内不触发。
- 格式命令的事务使用 `input.format` 并通过 `isolateHistory` 与之前的输入分开。
- 命令面板的三入口和三种模式在 `src/components/CommandPalette.vue`，模式解析、文件排序和最近文件记录在 `src/app/command-palette.ts`。命令模式过滤可用且当前可执行的注册表命令，编辑器命令在没有活动 Markdown 编辑器时不出现；执行后写入 `nicole:commands:recent`。面板和 slash 菜单共用 `loadPinyinMatcher()` 与 `filterCommands()`，`pinyin-pro` 仍只在第一次打开任一面板时加载。
- 用户模板由 `src/commands/snippets.ts` 转成普通命令，`App.vue` 在 slash 或命令面板打开时调用 `Workspace.ListSnippets(generation)` 并替换当前快照；Go 实现在 `workspace_snippets.go`。按编辑模式开关尚未实现，在后续设置的 PR 中完成。
