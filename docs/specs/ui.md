# 界面与交互

概要：

- 采用“装订册”布局：隐藏系统标题栏，侧栏从窗口顶部通到底部，放文件树；编辑区上方只有一行顶栏，放标签页、模式切换和大纲开关；大纲在编辑区右侧，默认隐藏；底部是一条细状态栏。
- 文件树按“单窗口多根目录”设计。P0 只允许一个根目录，换文件夹前提醒；P1 放开“添加文件夹”，界面结构不变。
- 文件树显示根目录下的所有文件。Markdown 用 Nicole 编辑，其他文件打开为“无法预览”的占位页。
- 正文里没有浮动工具栏，也没有自定义右键菜单。选中文字后的操作靠快捷键、输入标记字符包裹选区，以及默认关闭的固定格式工具栏。
- 文件树和标签页有原生右键菜单。
- 所有命令只在[命令注册表](slash-commands.md#命令注册表)里定义一次；本文的快捷键表是默认键位的唯一出处。
- 每项要求都带编号，后续 PR 按编号实现和验收；需要其他文档或后端配合的事项列在[待办](#待办)。

## 原则

- **写作优先**：界面不抢正文的注意力。常驻界面只有顶栏、侧栏和状态栏，其他界面都在用户主动触发时出现。
- **轻量**：空载内存预算见[性能](performance.md#预算)。目前的实测值已经超出预算（见[内存基线](../references/memory-baseline.md)），所以界面设计不增加不必要的常驻开销；每个 PR 的增量按[内存基线的更新约定](performance.md#内存基线的更新约定)记录和判断。
- **主题**：只使用 `@ayingott/theme` 的语义变量、`reading-*` 阅读层和 `src/style.css` 中的 `--nicole-*` 变量，Paper 和 Ink 都必须成立（见[主题与字体](theming.md)）。字体全部用系统字体。
- **文本规则**：菜单、按钮、标签和状态文字的末尾不加额外符号，例如写“打开文件夹”，不写“打开文件夹…”；写“保存中”，不写“保存中…”。按钮和空状态不显示快捷键，只把快捷键写进悬停提示和无障碍名称。菜单、命令面板和 slash 菜单在每一行右侧用 `KeyHint` 显示浅色纯文字（例如 `⇧⌘F` / `Ctrl+Shift+F`），不加重边框和底色；完整的快捷键列表以后放在设置面板里。下拉用图标表示，不在文字后加 `▾` 之类的字符。
- **平台**：以 macOS 为先，Windows 和 Linux 上布局同样成立。不同平台的文字差异只在本文明确列出的地方出现，例如“在 Finder 中显示”。

验收：

- **P-1** Nicole 自己写的菜单、按钮和状态文字都不以 `…`、`...`、`:`、`：`、`▾`、`›`、`>` 结尾；成对引号的后半个（例如对话框标题 切换到“博客” 末尾的 `”`）不算。MyGo 和更新插件自带的文字（例如“检查更新…”）不在此列。
- **P-2** 界面 CSS 只引用主题包的语义变量、`reading-*` 阅读层变量和 `--nicole-*` 变量，不写死颜色值。窗口控制按钮之类的平台元素除外。
- **P-3** 每个界面 PR 满足[内存基线的更新约定](performance.md#内存基线的更新约定)。

## 窗口与标题栏

- 窗口使用 MyGo 的隐藏标题栏：`TitleBarStyle: mygo.TitleBarHidden`。`TitleBarHeight: 40` 只对 Windows 和 Linux 生效；macOS 上用 `TrafficLightPosition` 让红绿灯在 40px 内垂直居中（MyGo 按“按钮高度 + 2 × Y”计算标题栏高度，Y 取使结果等于 40 的值，X 与侧栏左边距对齐）。页面绘制的顶部区域固定为 40px，不随 `--mygo-titlebar-height` 变化（全屏时该变量为 `0px`）；MyGo 的变量只用 `--mygo-titlebar-inset-left`、`--mygo-titlebar-inset-right` 来让出左右两侧窗口控制按钮的位置。
- macOS 的红绿灯在左上角，叠在侧栏顶部；侧栏隐藏时，顶栏左侧留出 `--mygo-titlebar-inset-left`。Windows 的最小化、最大化、关闭按钮在右上角，顶栏右侧留出 `--mygo-titlebar-inset-right`。Linux 按桌面环境给出的两个变量留白。全屏时左右两个变量为 `0px`，顶栏内容随之贴到左右边缘，高度仍是 40px。
- 顶栏和侧栏顶部的空白处标记为 `--app-region: drag`，可以拖动窗口。MyGo 只自动排除按钮、输入框、链接等原生可交互元素，自绘的标签页、模式切换分段等元素要显式标记 `--app-region: no-drag`。双击拖动区域时按系统行为缩放或最大化窗口。
- 菜单栏：macOS 使用 `main.go` 设置的应用菜单。Windows 隐藏标题栏后没有菜单栏位置，按 Alt 或 F10 时 MyGo 在左上角弹出菜单。Linux 默认隐藏菜单栏，按 Alt 或 F10 时显示。应用菜单之后是“文件”菜单，目前只有“关闭工作区”；菜单项通过页面事件调用命令注册表，不另写执行逻辑，也不绑定原生快捷键。
- 菜单项的快捷键不能与[快捷键](#快捷键)表冲突，也不能提供会丢失页面状态的操作。MyGo 默认的“显示”菜单（`RoleViewMenu`）包含“重新载入”⌘R、“强制重新载入”⇧⌘R，默认的“窗口”菜单（`RoleWindowMenu`）在 Windows 和 Linux 上把 Ctrl+W 绑定到关闭窗口，这些都要去掉或替换；“显示”菜单中的“切换开发者工具”（⌥⌘I、Ctrl+Shift+I）只在开发构建中保留；缩放（⌘+、⌘-、⌘0）和全屏保留。
- 应用主题与系统外观不同时，用 `mygo.Theme.SetSource` 同步，让原生菜单、右键菜单和对话框跟随应用主题。
- MyGo 0.7.3 的 `RoleUndo`/`RoleRedo` 在 macOS 上使用 AppKit 的 `undo:`/`redo:` selector，不会进入 CodeMirror 的历史。这两个菜单项改为向页面发送 `nicole:edit-command`，由页面执行 CodeMirror 的历史命令；输入法组合期间（`EditorView.compositionStarted`）忽略该命令。macOS 上已实测菜单点击、⌘Z 和 ⇧⌘Z 都作用于 CodeMirror 的历史，组合期间的忽略也有 Vitest 覆盖。Windows 和 Linux 的菜单事件行为**待实测**，见[待办](#待办)。
- 窗口启动时在光标所在的屏幕上居中，尺寸沿用上次保存的大小；规则和实现见[工作区与文件](workspace.md#窗口位置)（已由 #8 实现）。

验收：

- **W-1** 在 macOS、Windows 和 Linux 上，顶栏、标签页、模式切换和大纲开关都不被窗口控制按钮遮挡，全屏和退出全屏后也一样。
- **W-2** 进入全屏和退出全屏后，顶栏高度都是 40px。
- **W-3** 拖动顶栏空白处和侧栏顶部空白处都能移动窗口；拖动标签页不会移动窗口。
- **W-4** 系统为亮色、应用切到暗色后，右键菜单和原生对话框显示为暗色，反过来也一样。
- **W-5** 启动后窗口出现在光标所在的屏幕中央，尺寸与上次退出时一致。

## 整体布局

```text
+-----------+---------------------------------------------+
| A       B | C                                         D |
|           +---------------------------------------------+
| E         | F                                           |
|           +-------------------------------+-------------+
| G         | H                             | I           |
|           |                               |             |
| J       K +-------------------------------+-------------+
|           | L                                           |
+-----------+---------------------------------------------+
```

A 红绿灯（macOS）　B 隐藏侧栏　C 标签页　D 模式切换与大纲开关　E 搜索工作区　F 格式工具栏（默认关闭）　G 工作区工具行与文件树　H 正文　I 大纲（默认隐藏）　J 切换文件夹　K 主题切换　L 设置　M 状态栏

| 区域 | 尺寸 | 显示与隐藏 |
|---|---|---|
| 侧栏 | 默认 252px，可拖动右边缘在 200–400px 之间调整，双击边缘恢复默认；宽度全局记住 | ⌃⌘S 或侧栏顶部的按钮切换；隐藏后顶栏左侧出现显示侧栏的按钮 |
| 顶栏 | 固定高 40px，位于编辑区上方，左边与侧栏右边缘对齐 | 始终显示 |
| 格式工具栏 | 高 36px，在顶栏下方 | 默认关闭，见[固定格式工具栏](#固定格式工具栏) |
| 编辑区 | 填满剩余空间；正文最大宽度为 `--reading-measure`，在编辑区（不含大纲）内水平居中 | 有活动标签页时显示；否则显示[占位状态](#空状态) |
| 大纲 | 宽 220px，在编辑区右侧，位于顶栏（或格式工具栏）与状态栏之间 | 默认隐藏；顶栏最右的大纲开关或 ⌃⌘O 切换，开关全局记住，见[大纲](#大纲) |
| 状态栏 | 高 26px，只在编辑区下方，不延伸到侧栏；上边线与侧栏底部栏的上边线使用同一条 `--border-subtle`，两段水平对齐 | 始终显示 |

窗口宽度变化时：

| 窗口宽度 | 侧栏 | 顶栏 | 格式工具栏 |
|---|---|---|---|
| ≥ 960px | 固定在左侧，占据布局 | 标签页按需收缩 | 全部按钮 |
| 760–959px | 默认隐藏；打开时浮在编辑区上方，带阴影，不挤压正文；选择文件、按 Esc 或点击外部后收起 | 同上 | 放不下的按钮收进“更多”按钮的菜单 |
| 640–759px | 同上 | 模式切换收成一个图标按钮，点击后弹出三种模式 | 同上 |

大纲按侧栏右侧整块区域（下称内容区）的宽度决定位置，与侧栏是否显示无关：内容区宽度不小于 840px 时，大纲固定在右侧，占据布局；小于 840px 时，打开的大纲浮在内容区右上角，带阴影，不挤压正文。内容区为 840px 时，固定大纲后正文区域约 620px，扣除左右各 2rem 的内边距后约 556px，比 `--reading-measure` 窄，但按 18px 的正文字号每行仍能放下约 30 个汉字；默认窗口 1100px 减去侧栏 252px 后为 848px，大纲可以固定显示。

窗口最小尺寸为 640×480，由 `main.go` 限制。

验收：

- **L-1** 窗口宽度不小于 960px 时，侧栏与编辑区并排；拖动侧栏边缘可以在 200–400px 之间调整，重启后宽度保持。
- **L-2** 窗口宽度在 640–959px 之间时，打开侧栏不会改变正文的宽度和位置；按 Esc 或打开文件后侧栏收起。
- **L-3** 窗口最小时，顶栏的标签页、模式切换和大纲开关都可用，不换行，不互相重叠。
- **L-4** 隐藏侧栏后，正文仍水平居中，宽度不超过 `--reading-measure`。
- **L-5** 主题切换遵循[侧栏](#侧栏)中的位置和可见性规则，不另设浮层或第二个实例。

## 侧栏

### 结构

从上到下：

1. 顶部 40px：拖动区域，右侧是隐藏侧栏的按钮。macOS 上红绿灯位于左侧。
2. “搜索工作区”入口；右侧不显示快捷键，快捷键只写在悬停提示和无障碍名称里。点击后侧栏切换为[全文搜索](#全文搜索)。
3. 工作区工具行：高 26px，`role="group"`、`aria-label="工作区操作"`。左侧是工作区名称，11px 半粗、`--text-muted`，过长时省略；右侧是 4 个 22×22 的图标按钮，图标 14px、默认 `--text-muted`，悬停背景 `--surface-muted`、文字 `--text-primary`。四个按钮依次为“新建文件”（`file-plus`）、“新建文件夹”（`folder-plus`）、“全部折叠”（`chevrons-down-up`）和“更多”（`ellipsis`），都有悬停提示和 `aria-label`，有快捷键的带上快捷键文本。新建文件和新文件夹在工作区根目录创建，复用文件树的行内输入流程。工具行下方是文件树。
4. 底部一行：高 26px，上边线为 `--border-subtle`，与编辑区状态栏的上边线水平对齐。上边线占 1px 后内容区为 25px，行内按钮统一为 24×24，悬停背景不覆盖上边线。左侧是只显示 `folder-open` 图标的“切换文件夹”按钮，悬停提示和无障碍名称为“切换文件夹 ⌘O”（Windows/Linux 为 Ctrl+O）；右侧依次是同样尺寸、间距和悬停样式的主题切换按钮与设置按钮（齿轮图标，悬停提示“设置 ⌘,”），设置按钮点击打开[设置](#设置)。主题切换按钮在亮色时显示月亮、暗色时显示太阳，悬停提示“切换到亮色主题”或“切换到暗色主题”。P1 增加根目录入口后，这里是否改回带文字的“添加文件夹”另行决定。

主题切换只存在于侧栏底部和开始写作页的底部状态栏，不放在其他状态栏。侧栏显示时两种主题下都可见；侧栏收起或未打开工作区时，侧栏中的按钮不可见；未打开工作区时，开始写作页底部状态栏左侧的按钮使用同一个图标、尺寸和对齐方式。非 Markdown 占位页、设置标签页等只要侧栏显示就仍可见。

### 根目录与工具行

- 工作区名称只出现在工具行左侧，不再有单独的根目录行。根目录不能折叠整棵树；这个能力已移除。
- 工具行“更多”菜单用现有原生菜单显示“在 Finder 中显示”（Windows/Linux 用对应平台文字）、复制路径、分隔线和关闭工作区，在 Finder 中显示和关闭工作区通过命令注册表执行，复制路径由页面复制根目录绝对路径。
- 文件树空白处的右键菜单承接原根目录行菜单的“在 Finder 中显示”和“复制路径”，并在末尾新增分隔线和“关闭工作区”。原根目录行没有拖放处理，移除它不影响拖放。`role="tree"` 的节点层级和 `aria-level` 不变；可 Tab 进入的项按当前焦点、选中项、第一项的顺序回退，第一层按 ← 不离开树，删除焦点项后移到同级下一项、上一项或父级。
- **P0**：只有一个根目录。点击底部的“切换文件夹”按钮或按 ⌘O 选择另一个文件夹时，替换当前根目录，替换前提醒，见[切换文件夹](#切换文件夹)。
- **P1**：可以添加多个根目录，按添加顺序排列；“从侧栏移除”只移除显示，不删除文件。界面结构与 P0 相同，只是底部按钮的动作从“切换文件夹”变成“添加文件夹”，切换提醒不再出现；工具行按当前活动的根目录显示名称和操作。
- 搜索入口在 P0 统一称“搜索工作区”。P1 有多个根目录后，仍按工作区整体搜索并在结果中按根目录分组；是否改成“搜索全部文件夹”或增加范围选择，另行决定。
- 每个根目录的 `assets/` 和 `.nicole/` 只对这个根目录里的文件生效：粘贴和拖入的图片存到当前文件所在根目录的 `assets/`。
- 启动时按[启动恢复](#启动恢复)的规则恢复上次的根目录、标签页和活动标签页。上次的根目录已经不存在时，显示[未打开文件夹](#空状态)的状态；关闭状态下启动时不探测，用户尝试打开最近项时才按[最近打开](#最近打开)标记。

### 文件树

- 显示根目录下的所有文件和文件夹，包括空文件夹，带扩展名。`.md` 文件用 `--text-secondary`，其他文件用 `--text-muted`。
- 默认不显示：`.git`、`.DS_Store`、`Thumbs.db`、`desktop.ini`，以及 Nicole 写入时产生的临时文件（命名规则见[写入保证](workspace.md#写入保证)）。
- 以 `.` 开头的其他文件和文件夹（例如 `.nicole/`）照常显示，颜色为 `--text-muted`。
- `node_modules` 显示为 `--text-muted` 并保持折叠，展开时才读取内容。
- **按需读取**：打开根目录时只读取第一层；文件夹第一次展开时才读取它的下一层。全文搜索和链接补全仍各自扫描 `.md` 文件，沿用[列文件规则](workspace.md#列文件规则)中跳过隐藏目录和 `node_modules` 的规则。
- **排序**：文件夹在前，文件在后；同类按 `Intl.Collator("zh-Hans-CN", { numeric: true })` 排序，例如“第2章”排在“第10章”前面。
- **展开状态**：按根目录记在用户数据目录，不写进工作区。打开文件时自动展开它所在的各级文件夹，并把它滚动到可见位置。
- **单击**：`.md` 文件已经打开时切换到它的标签页，否则在活动标签页右侧新开一个；其他文件打开[无法预览的占位页](#非-markdown-文件)。不提供临时预览标签页。
- **键盘**：方向键移动、展开和折叠；重命名、打开、移到废纸篓和新建文件夹的键位见[快捷键](#快捷键)表的“文件树”一类，与各平台文件管理器的习惯一致。
- **新建**：在目标文件夹中出现一个行内输入框，默认名称为“未命名.md”，并预先选中“未命名”。输入的名称没有扩展名时，自动补上 `.md`。
- **重命名**：行内编辑，预先选中不含扩展名的部分。已打开的文件重命名后，标签页标题和路径同步更新。自动更新引用属于 P1（见[产品范围](product.md#p1)）。
- **外部变化**：文件监听到新增、删除和改名后，文件树在 1 秒内更新，展开状态和选中项保持不变。监听范围见[文件监听](workspace.md#文件监听)：隐藏目录（例如 `.nicole/`）和 `node_modules` 不监听，里面的变化在下次展开该目录时刷新。
- **后缀显示**：受[设置](#设置)中“隐藏 .md 后缀”控制，默认显示后缀。

### 全文搜索

- 点击“搜索工作区”或按 ⇧⌘F，侧栏切换为搜索视图：顶部是输入框（带区分大小写和正则开关），下面是结果。按 Esc 或清空输入框后回到文件树。
- 结果按根目录、文件、匹配行三级分组，匹配行最多显示一行上下文，匹配部分高亮。P0 只有一个根目录时，不显示根目录这一级。
- 结果通过 Channel 流式到达，边搜边显示；搜索进行中时，在结果上方显示“正在搜索”，完成后显示“3 个文件中有 5 处结果”。超过 1000 处时停止显示，并提示“结果过多，请缩小范围”。
- 点击匹配行时打开文件，选中匹配文字，并滚动到可见区域中部。
- 只搜索 `.md` 文件，见[工作区与文件](workspace.md#搜索)。

验收：

- **S-1** 打开一个包含 `node_modules`（超过 10 万个文件）的文件夹，文件树在 1 秒内显示第一层；展开 `node_modules` 之前不读取它的内容。
- **S-2** 文件树显示 `.md`、图片、PDF 和空文件夹，不显示 `.git`、`.DS_Store` 和 Nicole 的临时文件。
- **S-3** “第2章.md”排在“第10章.md”前面，文件夹排在文件前面。
- **S-4** 在监听范围内（不含隐藏目录和 `node_modules`）从外部新建、删除、改名文件，包括非 `.md` 文件，文件树在 1 秒内更新，原来的展开状态和选中项不变。
- **S-5** 全文搜索的结果边搜边出现；点击结果后打开文件并选中匹配文字。
- **S-6** P0 中，打开另一个文件夹会替换当前根目录；侧栏结构与多根目录时一致，只是工具行和文件树对应当前根目录。

## 标签页

### 外观与行为

- 标签页在顶栏里，高 28px，最小宽度 96px，最大宽度 200px。活动标签页使用 `--surface-subtle` 背景和 `--text-primary` 文字；其他标签页使用 `--text-muted`。
- 标题是文件名，后缀是否显示与文件树一致。标题超长时用 CSS 截断。悬停时提示“根目录名/相对路径”。
- 同名文件：多个标签页的文件名相同时，在文件名后用 11px 的 `--text-muted` 显示区分信息。不同根目录显示根目录名，例如“README.md 博客”；同一根目录显示上一级文件夹名。
- 关闭按钮只在活动标签页和鼠标悬停时显示。鼠标中键点击可以关闭标签页。
- 关闭处于保存失败、换行风格混合、外部修改未处理或文件已被删除状态的标签页时，不论用 ⌘W、中键、关闭按钮、右键菜单还是删除横幅上的“关闭标签页”按钮，都先显示确认对话框，按钮为“取消”和“放弃更改并关闭”。
- 自动保存是常态，所以普通的“编辑中”和“保存中”不在标签页上标示，只显示在[状态栏](#状态栏)。只有下列需要用户处理的状态，才在关闭按钮的位置显示一个圆点，并在悬停时说明原因：保存失败（`--status-danger-fg`）、换行风格混合（`--status-warning-fg`）、文件已在磁盘上被删除（`--status-danger-fg`）。
- 新标签页打开在活动标签页的右侧。标签页超出顶栏宽度后，在标签区域内横向滚动；切换标签页时，活动标签页自动滚动到可见位置。拖动排序属于 P1。
- 关闭最后一个标签页后，编辑区显示[占位状态](#空状态)。

### 后台标签页与恢复

[性能规格](performance.md#控制内存的手段)要求后台标签页只保留文本、销毁编辑器视图。切回时要恢复到离开前的样子：

| 保存的内容 | 恢复方式 |
|---|---|
| 文本 | 用它创建新的 `EditorView` |
| 选区，包括多选区 | 创建时作为初始选区 |
| 滚动位置 | 记录可见区域顶部那一行的行号和行内偏移；行号按扣除文档顶部内边距后的可见上沿计算，偏移为有符号像素值。新视图完成测量后把这一行滚动回同样的偏移，并在行高测量稳定前继续校正：最多 6 个动画帧，连续两帧写入的值不变即停。用户滚动或按键（wheel、touchstart、pointerdown、keydown）、文档改变、视图销毁或开始新的恢复时立即停止校正；文档改变不映射锚点，由新的恢复或用户操作接管 |
| 撤销历史 | 只在内存中按标签页保留：同一标签页切到后台再切回时，用 `EditorState.toJSON` 序列化 `historyField` 并恢复；沿用 CodeMirror 默认的 `minDepth: 100`，不放大。不写入 `tabs.json`，切换文件夹后重新打开或重启后不恢复，见[记住标签页](#记住标签页)。后台标签页的这部分占用计入[性能](performance.md#预算)中“打开 10 篇文档”的场景 |
| 查找条件 | 全局共享，不按标签页保存 |

编辑模式是全局的，切回的标签页使用当前模式。

### 非 Markdown 文件

- 在文件树中点击非 `.md` 文件时，打开一个占位标签页：页面中间是文件类型示意图，下面写“无法预览此类型的文件”，再下一行用浅色显示“文件名 · 大小 · 所在文件夹”，最下方是“用默认应用打开”和“在 Finder 中显示”两个按钮。
- 占位页不创建编辑器。状态栏左侧为空，不显示字数，也不显示保存状态。
- 以后在应用内预览图片时，替换这个占位页；布局和入口不变。

### 记住标签页

- 每个根目录各自记住打开的标签页、活动标签页，以及每个标签页的选区和滚动位置，保存在用户数据目录。
- 撤销历史只在本次运行期间按标签页保留，不按根目录持久化：同一标签页切到后台再切回时仍可撤销；切换文件夹后重新打开、重启后重新打开都从空历史开始。序列化的撤销历史可能很大，写进 `tabs.json` 会增加写盘和内存。
- P0 切换文件夹后再切回来，以及重启应用时，都恢复这些标签页。

验收：

- **T-1** 在标签页 A 选中一段文字并滚动到中间，切到标签页 B 再切回 A：选区相同；窗口尺寸不变时，可见区域顶部是同一行；⌘Z 能撤销切换之前的输入。
- **T-2** 后台标签页没有 `EditorView` 实例，DOM 中只有一个 `.cm-editor`。
- **T-3** 同一个根目录下，`随笔/README.md` 和 `旅行/README.md` 同时打开时，两个标签页分别显示“README.md 随笔”和“README.md 旅行”。（P1）两个根目录下各有一个 `README.md` 时，分别显示根目录名，例如“README.md 博客”和“README.md 写作”。
- **T-4** 连续输入时，标签页上不出现闪烁的圆点；让保存失败后，活动标签页出现红点，悬停时说明原因。
- **T-5** 打开 15 个标签页后，标签区域可以横向滚动，活动标签页始终可见，顶栏右侧的模式切换不被挤出窗口。
- **T-6** 点击 PNG 文件时打开占位页；“用默认应用打开”调用系统默认应用；“在 Finder 中显示”在 Finder 中选中该文件。
- **T-7** 重启应用后，上次打开的标签页、活动标签页、选区和滚动位置都恢复。
- **T-8** 让一个标签页保存失败，然后分别用 ⌘W、鼠标中键、关闭按钮和右键菜单中的“关闭”关闭它：每次都先出现确认；选择“取消”后标签页和内容都保留。从外部删除一个已打开的文件后，点击删除横幅上的“关闭标签页”，同样先出现确认。

## 编辑区

### 模式切换

- 顶栏右侧有一个三段式切换，文字为“预览”“沉浸”“源码”；悬停时显示完整名称和快捷键，例如“实时预览 ⌃⌘1”。
- 当前模式的分段使用 `--surface-subtle` 背景和 `--text-primary` 文字。切换模式不重建 `EditorView`（见[编辑模式](editor-modes.md#单一编辑器内核)）。
- 正文排版完全由 `reading-*` 变量决定，与模式切换控件无关。
- 模式切换的右边是顶栏最右的大纲开关，见[大纲](#大纲)。顶栏不放命令面板按钮，命令面板只通过快捷键打开。

### 大纲

大纲放在编辑区右侧，而不是左侧：

- 左侧已经有侧栏，两列导航挤在同一边，会把正文推离窗口中央。
- 放在右侧与侧栏左右对称，大纲开关在顶栏最右，与侧栏开关在左上角相对应。
- 正文在宽窗口中居中，右侧本来就有留白，大纲占用的主要是这块空间。

规则：

- 默认隐藏。顶栏最右的大纲开关（图标按钮，悬停提示“显示或隐藏大纲 ⌃⌘O”）、⌃⌘O 和命令面板都可以切换；开关状态全局记住。显示时开关按钮使用 `--surface-subtle` 背景。只在开始写作页（没有工作区且没有标签页）隐藏；无工作区但打开了单文件标签页时仍显示。
- 内容区宽度不小于 840px 时，大纲固定在右侧，宽 220px，背景与编辑区相同，没有边框；正文在剩下的宽度内居中。
- 内容区宽度小于 840px 时，大纲不会自动出现；点击大纲开关后，它临时浮在内容区右上角（顶栏下方 8px、右边 8px），高度随内容变化，最多到状态栏上方，使用浮层外观。点击其中的标题后自动收起，按 Esc 或点击外部也会收起。临时打开和收起不改变记住的开关状态。
- 顶部是 12px 半粗体的标题“大纲”，下面是当前文件的标题列表；只显示活动标签页的大纲。活动标签页不是 Markdown 文件或没有标签页时，大纲开关不可用，固定的大纲区域也不显示。
- 显示 H1–H3，按级别缩进。frontmatter 之后的第一个非空行是 H1、而且全文只有这一个 H1 时，它通常就是文章标题，不在大纲中显示。文档没有标题时，显示“没有标题”。
- 当前所在章节，即包含编辑区可见范围顶部那一行的标题，用 `--surface-subtle` 背景加左侧 2px 的 `--text-accent` 竖线标出，随滚动更新。
- 点击标题时，编辑区滚动到该标题，标题距可见区域顶部 24px，光标移到标题行的开头，焦点回到编辑区。
- 大纲在文档变化停止 300ms 后更新；中文输入法组合输入期间不更新。
- 不显示大纲时，可以用 ⇧⌘O（转到标题）按标题跳转，见[命令面板](#命令面板)。

### 选中文字后的操作

正文里不提供浮动工具栏，也不提供自定义右键菜单。选中文字后，可以这样操作：

1. **格式快捷键**：见[快捷键](#快捷键)。
2. **输入标记字符包裹选区**：规则见下表。
3. **固定格式工具栏**：默认关闭，见[固定格式工具栏](#固定格式工具栏)。
4. **命令面板**：打开命令面板时保留选区，执行的命令作用于选区。

选中文字后按 `/` 时替换选区，不打开 slash 菜单（见[Slash 命令](slash-commands.md#触发与开关)）。

**包裹规则**：只有下面五个条件同时满足时，输入的字符才会包裹选区；任何一条不满足，都像普通编辑器一样用输入的内容替换选区，不补出配对的括号或引号。

| # | 条件 | 不满足的例子 |
|---|---|---|
| 1 | 每个选区都不为空，而且都在同一行内 | 选区跨越多行或多个段落 |
| 2 | 输入的是半角字符 `*`、`` ` ``、`~`、`[` 之一 | 中文输入法输出的 `×`、`·`、`～`、`【`；`_`、`(`、`{`、`'`、`"`、`《` 等其他字符 |
| 3 | 字符来自直接按键 | 输入法组合中或上屏、粘贴、拖放、自动补全 |
| 4 | 选区完全位于普通正文中 | 选区在代码块、行内代码、frontmatter 或 HTML 块中 |
| 5 | 选区去掉首尾空白后仍不为空 | 只选中了空格 |

包裹后的结果：

- 选区首尾的空白留在标记外面，例如选中 ` 文字 ` 后输入 `*`，得到 ` *文字* `。
- 包裹后选区仍是原来的文字，不包括标记，所以连按两次 `*` 先得到斜体，再得到加粗；连按两次 `` ` `` 得到两层反引号，与 Markdown 的行内代码写法一致。
- `~` 一次就包成 `~~文字~~`，因为编辑器使用的 GFM 解析只把成对的 `~~` 识别为删除线；选区两侧已经是 `~~` 时，再输入 `~` 不做任何事。
- `[` 把选区变成 `[文字]()`：实时预览和源码模式下，光标停在括号里；沉浸模式下打开[链接弹框](#链接与图片弹框)。
- 一次 ⌘Z 撤销整个包裹。
- 输入字符只会添加标记，不会去掉标记；去掉格式用快捷键切换，例如再按一次 ⌘B。
- 三种模式下行为相同；沉浸模式下包裹后，标记照常隐藏。

与编辑器自带的括号自动配对（`basicSetup` 中的 `closeBrackets`）的关系：只要任一选区不为空，这一次输入就全部由 Nicole 按上面的规则处理，`closeBrackets` 不参与；多光标中有的选区为空时，不满足条件 1，不包裹，非空选区被替换，空选区处只插入输入的字符，也不补出配对。所有选区都为空时，`closeBrackets` 照常补出配对的括号和引号。处理包裹的输入处理器优先级高于 `closeBrackets`，因此有选区时输入 `[` 只会得到上面规定的结果。

不包括 `_`：CommonMark 不把夹在文字中间的 `_` 当作强调标记，而中文句子里的选区两侧几乎总是文字，用 `_` 包裹后大多不会渲染成斜体。另外，选区以标点开头或结尾、外侧又紧挨文字时（例如选中“工具”连同引号），按 CommonMark 规则 `*` 也可能不被识别为强调；这是 Markdown 语法本身的限制，Nicole 不为此改写选区或原文。

### 固定格式工具栏

- 位于顶栏下方，高 36px，横跨编辑区，按钮在编辑区内水平居中，下边有一条 `--border-subtle` 分隔线。工具栏的位置固定，不跟随选区。
- 默认关闭；在[设置](#设置)中，或在命令面板中执行“显示格式工具栏”“隐藏格式工具栏”来切换。开关全局记住。
- 按钮分三组，组之间有分隔线：
  - 加粗、斜体、删除线、行内代码、链接；
  - 段落类型下拉（正文、标题 1–3）、无序列表、有序列表、任务项、引用、代码块；
  - 表格、图片。
- 按钮的图标、名称和快捷键都从命令注册表读取；悬停提示为“名称 快捷键”，例如“加粗 ⌘B”。
- 按钮作用于当前选区；没有选区时作用于光标位置。点击按钮不让编辑器失去焦点，选区保持不变。
- 光标所在位置已经有某种格式时，对应按钮高亮（`--accent-soft` 背景），例如光标在加粗文字里时，“加粗”高亮。只在选区变化时检查一次语法树。
- 中文输入法组合期间，所有按钮暂时不可用。
- 三种模式下都可用。窗口窄时，放不下的按钮收进末尾的“更多”菜单。

### 链接与图片弹框

- 弹框锚定在链接或图片元素下方，空间不够时翻到上方。弹框宽 340px。
- 链接弹框有“文本”和“链接”两个输入框，以及“移除链接”“打开”“完成”三个按钮。Enter 等同于“完成”，Esc 取消修改并关闭。如果这个链接是刚刚用 ⌘K 或输入 `[` 新建的，按 Esc 时撤销这次插入（作为一个撤销步），不留下空的 `[文字]()`。
- 图片弹框有“替代文本”和“路径”两个输入框，以及“在 Finder 中显示”“完成”两个按钮。
- **打开方式**：任何模式下，按 ⌘K 都会打开链接弹框；没有选区时插入一个新链接。沉浸模式下，点击链接或图片会显示弹框，但焦点仍在正文；按 Tab 进入弹框。实时预览和源码模式下能看到 URL，所以只有 ⌘K 会打开弹框。三种模式下，⌘ 加点击（Windows 和 Linux 为 Ctrl 加点击）链接时只用浏览器打开链接，不增加选区；在链接以外的位置，⌘ 加点击仍是 CodeMirror 的“增加一个选区”（`clickAddsSelectionRange`）。

### 任务框

任务框按 #6 的实现自绘：外框、背景和勾选标记都由 CSS 绘制，读取 `--nicole-checkbox-*` 变量（见[编辑模式](editor-modes.md#当前实现)）。视觉要求如下：

| 部位 | 变量 | 取值 | Paper 对比度 | Ink 对比度 |
|---|---|---|---|---|
| 未勾选的外框 | `--nicole-checkbox-border` | `var(--text-muted)` | 5.65:1（对 `--surface-canvas`） | 7.42:1 |
| 未勾选的背景 | `--nicole-checkbox-bg` | `transparent` | — | — |
| 勾选后的外框与背景 | `--nicole-checkbox-checked-border`、`--nicole-checkbox-checked-bg` | `var(--text-accent)` | 5.84:1 | 10.09:1 |

#### 最近打开

- 标题“最近打开”居中，`--text-muted`，12px 半粗；最多显示 5 条，存储保留 10 条；没有记录时整块不显示。
- 每条是一个居中的圆角胶囊，内容为 `folder` 图标（14px，`--text-muted`）和文件夹名称（13px，`--text-primary`）。左右内边距对称，约 6px 16px；边框 `--border-default`，背景 `--surface-elevated`，悬停打开按钮所在内容时背景 `--surface-subtle`，使用 `focus-ring`；名称过长时省略，胶囊最大宽度 200px。
- 路径不显示在胶囊里：悬停提示使用 `displayPath` 形式（主目录写成 `~`）；打开按钮的无障碍名称是“打开 名称（路径）”。
- 同名文件夹使用 [标签页的同名区分逻辑](../../src/app/tabs.ts)（`distinguishingSuffixes`），在名称后追加浅色 11px 的上一级目录名，例如 `notes · Dropbox`；后缀也限制最大宽度并省略，名称始终保留可见宽度。
- 已不存在的文件夹：只有启动恢复或用户点击实际尝试打开该最近项、且 Go 返回固定的“目录不存在”错误时，才把它标记为“已不存在”；其他打开错误只显示中文打开失败提示，原始错误放在提示的悬停内容里，不混入界面文字；带原始错误的提示显示 8 秒，其他状态栏提示仍为 3 秒，打开文件夹成功时提前清除这类失败提示。最近项、选择文件夹、拖入和选择器失败都走同一套中文文案，原始错误只进悬停提示。标记后胶囊内容与边框变淡、名称加删除线，× 保持正常清晰度；打开按钮仍可用，点击会重新尝试打开：成功时清除该项标记，仍然不存在时保持标记并显示“文件夹已不存在”，其他错误保持原标记并显示打开失败提示。标记后的悬停提示和无障碍名称带上“已不存在，点击重试”；焦点留在同一个打开按钮上，不移到 ×。移除按钮始终显示。
- 移除按钮是独立可聚焦的圆形角标，浮在胶囊右上角：可见圆约 16px、图标约 10px，静止时背景 `--surface-elevated`、边框 `--border-default`、图标 `--text-muted`，24px 的可点区域向胶囊外扩展。悬停、按下或键盘 `focus-visible` 时，圆形背景为 `--surface-muted`、图标为 `--text-primary`，边框保持 `--border-default`，并保留 `focus-ring`；使用中性底色，不使用危险色。悬停 × 时胶囊内容保持 `--surface-elevated`，不显示打开按钮的悬停底色。普通项在悬停胶囊或键盘聚焦胶囊、× 时显示（平时用 opacity 隐藏但仍可聚焦），缺失项始终显示。角标绝对定位，不占主按钮内边距，主按钮左右内边距保持对称；相邻胶囊间距为角标外露部分留出空间，分行测量不包含角标，角标和焦点环不能被裁切。无障碍名称为“从最近打开中移除 名称”；同名时带上后缀，已不存在时带上状态。
- 分行使用纯函数和实际胶囊宽度：从 1 行开始逐个尝试行数 `r`；对每个 `r`，在“各行个数相差不超过 1”的所有分配中先试前面的行较多的分配（如 3+2），放不下再试其他分配（如 2+3），逐行用实际宽度加间距检查，取第一个全部放得下的结果。只有当前行数的所有均衡分配都放不下时才增加行数，因此不会仅仅因为第一行的切片放不下就让最后一行只剩 1 个；都放不下时每行 1 个。4 条需要两行时为 2+2；5 条在 3+2 放不下、2+3 放得下时为 2+3。窗口变窄时通过 `ResizeObserver` 重新分行。CSS `flex-wrap` 只能居中每条视觉行，不能把最后一行的一项回填到前面的行，所以选择 JS 分行。
- 移除胶囊后焦点移到下一项，没有下一项时移到上一项，列表为空时移到“打开文件夹”；标记缺失时焦点留在同一个打开按钮；其他项变化不改当前焦点。Tab 顺序保持最近使用的先后顺序。

### 拖入文件夹

- 只在开始写作页处理：把单个文件夹拖进窗口就打开它；此时没有工作区，不出现[切换文件夹](#切换文件夹)的确认。

### 外部修改与删除

- **外部修改，本地没有待保存内容**：直接载入磁盘上的新内容。载入时按新旧文本的差异生成一次修改，把选区映射到新内容上；载入前可见区域顶部那一行的开头也按同一次修改映射到新内容，滚动后这一行回到原来的行内偏移；这一行被删除时，映射到删除位置之后最近的一行。载入后在状态栏短暂显示“已载入磁盘上的新内容”，3 秒后恢复为保存状态。Nicole 自己写入引起的变化不触发这个提示。
- **外部修改，本地有待保存内容或保存失败**：暂停这个标签页的自动保存，编辑区顶部显示横幅：“此文件已在 Nicole 之外被修改”，按钮为“载入磁盘版本”和“保留我的版本”。选择“保留我的版本”后，下一次保存覆盖磁盘内容。
- **外部删除或移走**：暂停这个标签页的自动保存，横幅为“此文件已在磁盘上被删除或移走，内容仍保留在这个标签页中”，按钮为“重新保存”和“关闭标签页”。标签页显示红点。点击“重新保存”在原路径重建文件并立即刷新文件树。
- **根目录不可用**（例如移动硬盘被拔出）：文件树区域显示“无法读取文件夹”和重试按钮，这个根目录下的标签页显示删除横幅。

横幅位于顶栏（或格式工具栏）下方、正文上方，横跨编辑区，高度随文字变化。同一时间每个标签页最多显示一条横幅，优先级从高到低为：外部删除、外部修改、保存失败、这是恢复的内容（见[崩溃恢复](#崩溃恢复)）、换行风格混合、这个文件不在已打开的文件夹中（见[打开工作区之外的文件](#打开工作区之外的文件)）。高优先级的横幅处理完后，显示下一条仍然成立的横幅。

### 崩溃恢复

- 启动时如果发现恢复副本（见[工作区与文件](workspace.md#崩溃恢复)），在窗口中央显示模态对话框：标题“发现未保存的内容”，说明“Nicole 上次没有正常退出，以下文件有比磁盘更新的内容”。
- 列表每项显示文件名、工作区相对路径或单文件完整路径、副本时间和字数差。字数差是副本减磁盘：`多 N 字`、`少 N 字` 或 `字数相同`。`changed` 项改标“磁盘上的文件已更改”，`missing` 项改标“文件已不存在”，无法通过安全复核的单文件副本标“无法恢复”。
- 字数差使用统一字符计数：CJK 字符（汉字、假名、谚文）每个计 1；其他文字按连续字母或数字串计 1；空白和标点不计；不剥 Markdown 标记。口径只在本节定义一次，P1 状态栏复用同一实现。
- 时间显示为“今天 23:41”“昨天 09:12”，更早显示“11月2日 09:12”，使用 `Intl.DateTimeFormat` 和本地时区。
- 按钮：“全部丢弃”（`--status-danger-fg` 文字）、“逐个查看”、“全部恢复”（主按钮）。Esc 等同于“逐个查看”，不丢数据、不写盘。
- “全部恢复”：按[磁盘状态](workspace.md#磁盘状态与恢复)的三态规则处理。磁盘未变的副本进入标签页，约 1 秒后由自动保存写回；`changed` 和 `missing` 不自动保存，分别显示外部修改和删除横幅。
- “逐个查看”：依次打开相关标签页，磁盘未变的标签显示横幅“这是恢复的内容”，按钮为“保留恢复内容”和“使用磁盘版本”。横幅回答之前该标签暂停自动保存。`changed` 和 `missing` 仍按横幅优先级显示外部修改或删除横幅。
- 用户点击“全部恢复”“逐个查看”或“保留恢复内容”时重新读取磁盘状态，以最新的 `diskState` 和 `diskText` 为准。对话框打开期间磁盘被同步盘或 `git pull` 改变时，恢复项转为外部修改或删除，不自动写回；已有标签的基线比列表快照新时，不用旧快照覆盖。保留恢复内容前也重新核对：等待期间标签被 watcher 更新时放弃强制保存；不能只看 `diskState`；不可恢复的副本不写盘，`missing` 转删除，否则 `diskText` 与恢复时基线相同就写回，不同才显示外部状态、不强制保存。
- 对话框打开期间不能编辑；只暂停写入列表中列出的文件，其他标签照常自动保存（ST-8）。`AppDialog` 的焦点陷阱和焦点恢复同样适用。启动时由系统转交的打开文件在恢复对话框关闭后再处理，不叠加另一个对话框。
- 当前根目录有副本时显示上面的列表。其他根目录只计数，在列表底部显示“另外 N 个文件夹还有未保存的内容，打开它们时会提示”；打开那个文件夹并恢复布局后，再显示同一个对话框。
- 最近文件夹已不存在、进入“开始写作”空状态时，单文件副本仍会显示对话框。“全部丢弃”只删除列出的副本，磁盘文件保持不变。

验收：

- **R-1** 连续输入 10 秒不停顿：约 2 秒出现副本，之后每 5 秒更新；停止输入后自动保存成功，副本删除。
- **R-2** 把文件设为只读使保存失败：副本立即写出；恢复权限后点“重试”成功，副本删除。
- **R-3** 有副本时用 `kill -9` 结束进程后启动：先显示恢复对话框，列出文件名、时间和“多 N 字”；用户选择前磁盘文件的修改时间不变（ST-8）。
- **R-4** “全部恢复”：磁盘未变的文件进入标签页并在约 1 秒后写回；对话框打开期间无法编辑。
- **R-5** 写副本后由另一编辑器修改磁盘文件，再模拟崩溃启动：该项标注“磁盘上的文件已更改”；全部恢复后该标签显示外部修改横幅，不触发自动保存；“载入磁盘版本”后副本删除。恢复对话框保持打开时再次修改磁盘，选择全部恢复后同样按最新的外部修改处理，不用打开对话框时的快照覆盖。
- **R-6** 写副本后删除磁盘文件：该项标注“文件已不存在”；恢复后显示删除横幅，“重新保存”在原路径重建文件。
- **R-7** “逐个查看”：横幅上的“保留恢复内容”和“使用磁盘版本”分别写回和载入磁盘版本，并删除副本；选择“保留恢复内容”前磁盘已变化时改为显示外部修改横幅，不写盘。
- **R-8** “全部丢弃”只删除列出的副本，磁盘不变，其他根目录的副本不受影响。
- **R-9** 单文件有未保存内容时崩溃：启动对话框列出完整路径；恢复后可继续编辑并自动保存；页面以不存在的副本 id 调用恢复接口被拒绝；Go 单测覆盖“未授权路径写副本被拒绝”和“恢复不存在于 recovery 目录的 id 被拒绝”。
- **R-10** 两个根目录各有副本：启动只列最近根目录的，底部说明“另外 1 个文件夹……”；切到另一个根目录后再次出现对话框。
- **R-11** 向 `recovery/` 放一个非 JSON 文件后启动：被改名为 `.corrupt-*`，其余副本正常列出。
- **R-12** 关窗时保存失败并选“仍然关闭”：副本保留，下次启动继续提示。
- **R-13** 单元测试覆盖字数口径（中英混合、标点、空白）、副本计时不随按键重置、上限拒绝策略。
- **R-14** 空载内存按[性能](performance.md#测量方法)的约定测量并记录，不因恢复服务超出预算。

### 切换文件夹

仅适用于 P0（只有一个根目录）：

- 选择另一个文件夹前，显示确认对话框。以切换到“博客”为例：标题为：切换到“博客”；说明为：当前文件夹的 5 个标签页会关闭，切回“写作”时会恢复这些标签页；按钮为“取消”和“切换”。
- 有保存失败或换行风格混合的标签页时，对话框列出这些文件，按钮改为“取消”和“放弃更改并切换”。
- 这个页面对话框代替当前实现中切换文件夹前调用的 `ConfirmDiscard()`（见[保存](workspace.md#保存)），同一次切换不再弹出原生确认框。多标签页界面中切换文件只是切换标签页，内容保留在标签页里，不需要确认。批量关闭标签页的确认同样用页面对话框，见[右键菜单](#右键菜单)。
- 切换前等待恢复副本删除和进行中的副本写入，最多 5 秒。超时则取消切换，重新保护脏标签，工作区、标签页和侧栏保持原样，显示“切换文件夹失败：恢复副本仍在写入”。
- 打开目标文件夹失败时，工作区、标签页和侧栏保持原样，脏标签重新写出恢复副本，并显示打开失败原因。

### 关闭工作区

- 命令注册表中有一条 `app.close-workspace`“关闭工作区”命令，命令面板可以找到并执行。它没有默认快捷键，避免与关闭标签页的 ⌘W / Ctrl+W 混淆。入口包括原生“文件”菜单、侧栏工具行的“更多”菜单和文件树空白处右键菜单；三处都触发这条命令。
- 没有打开工作区时命令不可执行，命令面板不列出它；“文件”菜单项仍显示，但页面收到命令后不执行任何操作，也没有副作用。
- 关闭前先保存所有标签页（包括单文件标签页）。有保存失败、换行风格混合、外部修改或删除等需要确认的标签时，显示页面对话框：标题“关闭工作区？”，说明“当前文件夹的 N 个标签页会关闭，下次打开‘文件夹名’时会恢复这些标签页”，列出有问题的文件，按钮为“取消”和“放弃更改并关闭工作区”。没有问题时直接关闭，不再确认。
- 取消时工作区、标签页和侧栏都不变，只保留已经成功保存的内容；这和切换文件夹取消时的行为一致。
- 确认或无需确认时：先写入当前根目录的 `tabs.json` 布局，等待相关恢复副本的删除和进行中的副本写入完成（最多 5 秒；超时则取消关闭，重新保护脏标签并显示“关闭工作区失败：恢复副本仍在写入”），再停止文件监听、关闭单文件授权、清空标签页，回到开始写作页并隐藏侧栏；焦点移到开始写作页的“打开文件夹”按钮。`tabs.json` 保留，下次打开这个文件夹时恢复布局。该文件夹排到最近打开的第一位。用户选择放弃时，相关恢复副本按[崩溃恢复](workspace.md#崩溃恢复)的规则删除；成功保存的标签不留下副本。Go 端关闭失败时标签页、单文件授权和工作区都保留，脏标签重新开始写恢复副本。
- 关闭后的 Go 行为见[工作区与文件](workspace.md#没有打开的根目录)。

### 打开工作区之外的文件

通过文件关联打开一个 `.md` 文件，或把它拖到标签栏上时：

1. 文件在当前根目录里：打开它，并在文件树中定位。
2. 文件在最近用过的某个文件夹里：P0 走[切换文件夹](#切换文件夹)的确认；P1 直接添加该文件夹并打开文件。
3. 都不是：显示对话框“这个文件不在已打开的文件夹中”，按钮为“只打开这个文件”“打开所在文件夹”（P1 为“添加所在文件夹”）和“取消”。所在文件夹是主目录或磁盘根目录时，“打开所在文件夹”不可用，并在悬停时说明原因。该父目录授权一次性使用：打开后由 Go 消耗；取消、关闭对话框或打开失败后由页面调用 `DismissOfferedFile` 消耗。

“只打开这个文件”打开一个单文件标签页：标签页悬停提示显示完整路径，编辑区顶部显示一条信息横幅“这个文件不在已打开的文件夹中”，自动保存照常进行；文件树不变。单文件标签页不属于任何根目录：P0 切换文件夹时保留，不计入确认对话框中“会关闭”的标签页数量；它不随根目录记住，重启后不恢复。

验收：

- **ST-1** 首次启动显示“开始写作”和“打开文件夹”；打开文件夹后显示文件树和“选择一个文件开始写作”。
- **ST-2** 让保存失败（例如把文件设为只读）：状态栏显示“保存失败”，横幅显示简短的中文原因（原始错误在悬停提示中）和“重试”，标签页显示红点；恢复权限后点击“重试”，横幅消失，状态变为“已保存”。
- **ST-3** 保存在 300ms 内完成时，状态栏不出现“保存中”。
- **ST-4** 在另一个编辑器里修改一个已打开、已保存的文件：Nicole 自动载入新内容，并显示“已载入磁盘上的新内容”；Nicole 自己保存时不出现这条提示。
- **ST-5** 光标在第 20 行的某个词后面，外部在第 5 行前插入 3 行：载入后光标仍在同一个词后面（第 23 行），可见区域顶部仍是载入前的那一行。
- **ST-6** 在本地有待保存内容时从外部修改文件，出现外部修改横幅，自动保存暂停，直到用户做出选择。
- **ST-7** 从外部删除已打开的文件：出现删除横幅，内容仍在；点击“重新保存”后文件在原路径重新出现。
- **ST-8** 存在恢复副本时启动，先显示恢复对话框；用户选择之前，磁盘文件不被改写。
- **ST-9** P0 中打开另一个文件夹前出现确认；切回原文件夹后，原来的标签页恢复。
- **ST-10** 双击一个位于下载文件夹的 `.md` 文件，出现“这个文件不在已打开的文件夹中”的对话框；选择“只打开这个文件”后，文件树不变，文件可以编辑并自动保存。
- **ST-11** 打开一个文件夹并打开两个文件，从命令面板、“文件”菜单、工具行“更多”菜单或文件树空白处右键菜单执行“关闭工作区”：先保存能保存的标签，再回到开始写作页，侧栏隐藏，焦点在“打开文件夹”；重新打开这个文件夹时恢复两个标签和布局。有保存失败的标签时出现确认，选择“取消”后工作区、标签和侧栏都不变；选择“放弃更改并关闭工作区”后关闭。没有打开工作区时命令面板不列出“关闭工作区”，点击“文件 > 关闭工作区”没有副作用。
- **ST-12** 关闭工作区后退出，再启动：直接显示开始写作页，不恢复上次的文件夹。不关闭工作区就退出，再启动仍恢复上次的文件夹和标签。打开任意文件夹后，`settings.json` 中不再保留表示关闭状态的字段。
- **ST-13** 最近打开有 7 条记录时按[最近打开](#最近打开)的上限显示，存储保留上限；同名区分、缺失项点击重试、右上角移除角标和分行行为符合该节规则。
- **ST-14** 未打开工作区时，开始写作页的主题按钮按[侧栏](#侧栏)的布局显示；点击切换亮暗并保存设置，悬停提示随当前主题变化。打开工作区后，这个按钮消失，侧栏底栏的同名按钮可用。
- **ST-15** 在开始写作页拖动一个文件夹进入窗口：出现虚线框和“松开以打开文件夹”，松开后打开该文件夹。拖入两个项目、一个普通文件、一个不存在的路径或一个符号链接时不打开文件夹，并显示“只能拖入一个文件夹”。有工作区、页面对话框或启动恢复未结束时拖动文件夹不触发打开工作区。
- **ST-16** 编辑文件、让保存失败并等到恢复副本写出，关闭工作区时选择“放弃更改并关闭工作区”：重新打开该文件夹后不再出现刚放弃的恢复副本。Go 端关闭失败时，标签页、单文件授权和工作区都保留，脏标签重新写出恢复副本。
- **ST-17** 侧栏工具行显示工作区名称、新建文件、新建文件夹、全部折叠和更多。新建文件和新建文件夹在根目录进入行内输入；全部折叠收起所有文件夹并在重启后保持，命令面板也能执行“全部折叠”；“更多”菜单显示“在 Finder 中显示”（Windows/Linux 用对应文字）、复制路径和关闭工作区；文件树空白处右键菜单包含显示、复制路径和关闭工作区。文件树没有根目录行，节点层级和键盘起点不变。
- **ST-18** 恢复副本写入超过 5 秒时，关闭或切换被取消：工作区、标签页和侧栏不变，脏标签重新写出副本，并显示对应的“恢复副本仍在写入”提示。

## 浮层与面板

所有浮层使用同一套外观：`--surface-elevated` 背景，`--border-default` 边框，`--radius-card` 圆角，`--shadow-lg` 阴影，界面字体 13px。层级使用主题包的 z-index 变量：

| 浮层 | 位置 | 层级 | 打开方式 | 关闭方式 |
|---|---|---|---|---|
| 大纲 | 内容区宽度不小于 840px 时固定在右侧；否则临时浮在内容区右上角 | 布局内；浮动时为 `--z-popover` | 大纲开关、⌃⌘O | 大纲开关、⌃⌘O；浮动时还可以按 Esc、点击外部或点击标题 |
| 查找替换 | 正文区域右上角，距顶栏下边 8px、右边 14px，宽 380px；有格式工具栏时位于其下方；大纲固定显示时，右边对齐大纲的左边缘 | `--z-popover` | ⌘F 只显示查找行；⌥⌘F 同时显示替换行 | Esc |
| 全文搜索 | 替换侧栏中的文件树 | 布局内 | ⇧⌘F，或点击侧栏的搜索入口 | Esc，或清空输入框 |
| 窄窗口浮出的侧栏 | 窗口左侧，从顶栏到底部覆盖内容区；对话框打开时保持打开并位于其下 | `--z-header` | 侧栏开关、⌃⌘S | 侧栏开关、⌃⌘S、Esc、点击内容区，或打开命令面板 |
| 命令面板 | 水平居中，距窗口顶部 72px，宽 `min(560px, 100% - 48px)`，下面有一层浅色遮罩 | `--z-overlay` | ⇧⌘P、⌘P、⇧⌘O | Esc，点击遮罩，或执行一条命令 |
| slash 菜单 | 锚定在光标下方，空间不够时翻到上方，宽 260px，最多显示 8 项 | `--z-popover` | 在行首或空格后输入 `/`，或输入法输出的 `、` | Esc，光标离开触发位置，查询没有匹配项，或执行一条命令 |
| 链接与图片弹框 | 锚定在元素下方，空间不够时翻到上方 | `--z-popover` | 见[链接与图片弹框](#链接与图片弹框) | Esc，或“完成” |
| 对话框（崩溃恢复、切换文件夹等） | 窗口中央，宽 440px，带遮罩 | `--z-modal` | 由状态触发 | 按钮；Esc 等同于“取消”，崩溃恢复对话框的 Esc 等同于“逐个查看” |
| 原生右键菜单 | 鼠标位置 | 系统 | 右键 | 系统 |

规则：

- 同一时间只显示一个 `--z-popover` 层级的浮层，只有查找替换可以和 slash 菜单、链接弹框同时存在。打开命令面板时，先关闭所有 `--z-popover` 浮层和窄窗口浮出的侧栏；打开对话框时只关闭 slash 菜单和模式菜单，浮出侧栏保持打开并留在对话框下方，以便关闭对话框后焦点回到发起操作的控件。Nicole 依赖这条“先关闭”规则，不依赖 z-index 顺序。
- `@ayingott/theme` 0.4.0 的 z-index 数值顺序是 `--z-popover`（1000）高于 `--z-modal`（900）和 `--z-overlay`（800），与“后打开的界面在上”不一致。浮出侧栏使用 `--z-header`（200），低于 overlay 和 modal，作为漏关时的兜底，不作为 popover 层使用。
- 编辑器宿主建立独立的层叠上下文（`isolation: isolate`），把 CodeMirror 自带查找面板和 tooltip 的 z-index 限制在编辑区内；否则 PR9 之前 `.cm-panels` 的 `z-index: 300` 会盖住 `--z-header` 的浮出侧栏。
- Esc 只关闭最上层的浮层或临时界面，处理顺序（不是 z-index 顺序）从上到下为：对话框、命令面板、`--z-popover` 浮层、临时浮出的大纲、窄窗口下浮出的侧栏、全文搜索视图。都没有时，Nicole 不处理 Esc，交给编辑器（例如折叠多选区、取消输入法组合）。
- 所有浮层在窗口边缘内保留 8px 间距，不超出窗口。
- 浮层打开时焦点进入浮层，关闭后焦点回到打开前的位置。slash 菜单和沉浸模式下点击链接显示的弹框不抢焦点。
- 输入法组合期间（`KeyboardEvent.isComposing` 为真，或 `keyCode` 为 229），slash 菜单、命令面板和上面的 Esc 关闭顺序都不处理这次按键，Enter、↑、↓、Esc 等一律交给输入法。

### 查找替换

- 第一行：查找输入框（右侧有区分大小写和正则开关），右边是“4/12”样式的计数、上一个、下一个和关闭按钮。第二行（⌥⌘F 时显示）：替换输入框、“替换”和“全部替换”。
- 所有匹配用 `--status-warning-bg` 背景加 `--status-warning-border` 描边；当前匹配用 `--accent-soft` 背景加 `--focus-ring-color` 描边。
- 打开查找时，如果有选区且在一行之内，用选中的文字作为查找内容。

### 命令面板

- 三种入口共用一个面板，输入框只保存查询文字，模式由输入框左侧的浅色界面字体标识和占位文字表示：
  - ⇧⌘P 打开命令模式，左侧显示 `>`，列出命令注册表中 `available !== false` 且当前上下文可执行的命令，右侧用浅色纯文字的 `KeyHint` 显示快捷键；没有打开工作区时，“关闭工作区”“重新打开关闭的标签页”这类依赖根目录的命令不列出；没有打开的标签页时，“关闭标签页”不列出；
  - ⌘P 打开文件模式，没有模式标识，列出当前根目录下的 `.md` 文件，选中后打开或切换到已有标签页；
  - ⇧⌘O 打开标题模式，左侧显示 `@`，列出当前 Markdown 文件的标题，选中后跳转。
- **命令范围**：应用命令总是列出；编辑器命令只在有活动 Markdown 编辑器时列出，没有编辑器时不显示而不是标为不可用；文件树命令依赖文件树焦点，不在面板中列出。`available: false` 的占位命令都不显示。
- **文件来源与排序**：每次打开面板都调用 `ListFiles()`，不常驻缓存；只有 `.md` 文件，规则与[列文件规则](workspace.md#列文件规则)一致。没有查询时最近激活的文件在前，其余按路径排序；有查询时先按匹配度，再按最近次序和路径。最近文件的记录随当前根目录写入 `tabs.json`，最多 20 条，见[标签页存储](workspace.md#标签页存储)。没有根目录时显示“先打开一个文件夹”。
- **标题来源**：标题在本次面板会话中第一次进入标题模式时从活动文档的 Lezer 语法树读取并缓存；只在命令或文件模式打开面板时不做提取，避免大文档阻塞打开。读取 `ATXHeading1–6` 和 `SetextHeading1–2`，按标题层级缩进显示，字号和标记不改变标题文字；多行 Setext 内容合并为一行；引用和列表里的标题去掉 `>`、`-` 等容器前缀，空标题用浅色“空标题”占位。语法树在 250ms 内没有解析完时，继续列出已解析的标题，并在列表末尾显示“文档较大，部分标题尚未解析”。选中后把标题行滚到编辑区顶部，光标放到该行行首，焦点回到编辑器。没有活动 Markdown 标签时显示“当前没有打开的 Markdown 文件”，文档没有标题时显示“当前文档没有标题”。
- 搜索支持拼音模糊匹配（`pinyin-pro`，见[Slash 命令](slash-commands.md#搜索与排序)）。命令模式中最近用过的命令排在前面，记录位置和上限见[搜索与排序](slash-commands.md#搜索与排序)；文件模式使用同一套拼音匹配。
- **模式切换**：文件模式且查询为空时输入 `>` 或 `@` 会切换到命令或标题模式，该字符不进入输入框；查询非空时这两个字符按普通查询文字处理。向空输入框粘贴以 `>` / `@` 开头的文字同样切换并去掉首字符。命令或标题模式查询为空、光标在开头且没有选区时，按 Backspace 回到文件模式。⌘P、⇧⌘P、⇧⌘O 切换模式并保留查询文字。输入法组合期间不处理，组合结束后再判断。
- **模式播报**：面板里有一个 `sr-only` 的 `role="status"`、`aria-live="polite"` 区域。上述输入或粘贴 `>` / `@`、空查询 Backspace 和面板内 ⌘P/⇧⌘P/⇧⌘O 切换模式时，写入“命令模式”“文件模式”或“标题模式”，文字与 `paletteModeLabel` 一致。打开面板时不写入，初始模式已经由对话框标题和输入框 `aria-label` 表达；连续切到同一种模式时仍会再次播报。每次先清空区域，再在短延迟（当前 50ms）后写入新文字，避免两个 WebView 把清空和写入合并成一次没有变化的更新。关闭面板时清空区域。
- 输入行左右内边距 16px；命令和标题模式的浅色界面字体标识与输入文字视觉中心对齐，与输入框间隔 8px；文件模式没有标识，输入框占满剩余宽度。输入框不使用 `focus-ring`，也不显示浏览器默认 outline，焦点由光标和面板本身表示。
- 输入框是 `role="combobox"`，列表是 `role="listbox"`，选中项通过 `aria-activedescendant` 关联，`aria-expanded` 在面板打开期间为真。输入框是面板唯一的 Tab 停靠点，Tab 不离开面板；点击面板内空白处时焦点留在输入框。
- 面板打开期间，⌘P、⇧⌘P、⇧⌘O 分别切换到文件、命令、标题模式，只改变模式，已经输入的查询文字保留；已经处于目标模式时保持不变（仍播报当前模式）。
- 面板打开期间，活动文档被外部载入、图片插入或其他非面板发起的改动改变时，面板关闭；执行编辑器命令或标题跳转前还会核对打开时记录的文档版本，已经变化就放弃，不把旧位置写进新文档。
- 打开面板时保留编辑器选区；执行编辑器命令前先把焦点还给编辑器，并用打开时记下的选区覆盖一次，再运行命令，因此命令作用于这个选区。
- 执行命令、按 Esc 或点击遮罩都关闭面板。打开时关闭 slash 菜单、链接弹框、模式菜单和其他 `--z-popover` 浮层；有 `--z-modal` 对话框时不打开面板。输入法组合期间不处理 Enter、↑、↓、Esc 和无匹配判断。

### slash 菜单

- 触发条件（包括中文输入法下的 `、`）、内置命令和排序见[Slash 命令](slash-commands.md)。
- 菜单顶部用浅色显示当前输入的查询，例如“/biao”。每项左侧是 22px 的示意（例如 `H2`），中间是名称，右侧是浅色纯文字的快捷键（`--text-muted`，11px，右对齐，没有边框和底色）。
- 执行命令后删除触发字符和查询文字，删除查询和执行命令是同一个撤销步，也不与之前的输入合并。查询没有匹配项或出现空白（包括紧跟触发符的空格）时，菜单直接关闭；组合输入期间等到组合结束后再判断。按 Esc 关闭菜单、光标离开触发位置，或者因为没有匹配项、出现空白而关闭时，保留已经输入的 `/` 或 `、` 和查询文字，不做删除。
- 触发位置在围栏代码块、缩进代码块、行内代码、frontmatter 或 HTML 块内时不打开菜单，见[Slash 命令](slash-commands.md#触发与开关)。

- **F-2** 打开命令面板时，slash 菜单和链接弹框会关闭；在命令面板中执行“加粗”时，作用于打开面板前的选区。
- **F-3** 在中文输入法下，于行首按 `/` 键（输出 `、`），打开 slash 菜单；在句中两个汉字之间输出 `、`，不打开菜单。
- **F-4** 光标在窗口底部附近时，slash 菜单翻到光标上方，不超出窗口。
- **F-5** 关闭任何浮层后，焦点回到打开前的位置；从编辑器打开的，光标位置不变。
- **F-6** 用 `、` 打开 slash 菜单后继续用拼音输入，在组合期间按 Enter：拼音按原样上屏，不执行菜单中的命令；组合期间按 ↑↓ 只切换候选词，不移动菜单选中项；组合期间按 Esc 只取消组合，slash 菜单保持打开。
- **F-7** 在命令面板的输入框中用拼音输入，组合期间按 Enter：拼音按原样上屏，不执行当前选中的命令。
- **F-8** 在 slash 菜单中继续输入，直到查询没有匹配项：菜单自动关闭，`/` 和查询文字原样保留在正文中；再输入的文字照常进入正文。在有匹配项时按 Esc，菜单同样关闭，已输入的文字保留。
- **F-9** 按 ⌘P 列出根目录下全部 `.md` 文件，最近激活过的在前；选中一个尚未打开的文件会打开它，选中已打开的标签页会切换过去，不产生重复标签。
- **F-10** 按 ⇧⌘O 列出当前文档的 ATX 和 Setext 标题，按层级缩进；选中后标题行位于编辑区顶部，光标在行首，焦点回到编辑器。
- **F-11** 文件模式且查询为空时输入 `>` / `@` 会切换到命令 / 标题模式，该字符不留在输入框；查询非空时这两个字符只是普通查询文字。命令或标题模式查询为空、光标在开头且没有选区时按 Backspace 回到文件模式；有查询、光标不在开头或有选区时不切换。向空输入框粘贴以 `>` / `@` 开头的文字按同样规则切换并去掉首字符；输入法组合结束后再判断。切换后列表和空状态随之更新。
- **F-12** 在命令模式输入 `jiacu` 能匹配“加粗”；执行后它进入最近命令列表，下一次打开面板时排在最前。
- **F-13** 命令面板打开时，已有的 slash 菜单、链接弹框和模式菜单都关闭；按 Esc 只关闭命令面板，不执行选中命令，也不继续关闭其他界面。
- **F-14** 从未打开过 slash 菜单或命令面板时，`pinyin-pro` 不在空载 bundle 中；第一次打开面板后才作为独立懒加载 chunk 载入。
- **F-15** 在命令面板中切换模式时，面板内的状态区域写入对应的“命令模式”“文件模式”或“标题模式”：输入或粘贴 `>` / `@`、空查询 Backspace、面板内 ⌘P/⇧⌘P/⇧⌘O 都会触发；打开面板时不写入；连续切到同一种模式时再次播报；关闭面板后区域清空。

## 快捷键

- 下表是默认键位的唯一出处。实现时，每条快捷键都写在命令注册表对应命令的“快捷键”字段里，slash 菜单、命令面板、格式工具栏、右键菜单和悬停提示都从注册表读取，不在其他地方另写键位（见[Slash 命令](slash-commands.md#命令注册表)）。
- 注册表的键位使用 CodeMirror 写法，`Mod` 在 macOS 上是 ⌘，在 Windows 和 Linux 上是 Ctrl。两个平台不只是 ⌘ 与 Ctrl 互换的命令（例如查找并替换、下一个匹配），以及有多个键位的命令（例如下一个标签页），按[命令注册表](slash-commands.md#命令注册表)“快捷键”字段的分平台、多键位写法登记。界面显示时按平台转换为符号或文字。
- 界面中可见的快捷键只有一种呈现（`KeyHint`）：连续文本，例如 `⇧⌘F` 或 `Ctrl+Shift+F`，系统界面字体 `--font-sans`、11px、`--text-muted`，没有边框、底色和阴影。菜单、命令面板和 slash 菜单在每行右侧显示它；按钮和空状态不显示快捷键，只把同一段文本放进悬停提示和无障碍名称。
- 快捷键文本都由同一处平台格式化函数生成。完整的快捷键列表以后放在设置面板里；在此之前，菜单和命令面板是查看键位的主要入口。
- `KeyHint` 对读屏隐藏，父级用 `aria-label` 或 `sr-only` 文本提供连续的快捷键字符串；已经有 `aria-label` 的地方不重复朗读。
- Windows 和 Linux 的键位避开 Ctrl+Alt 组合，因为它在部分键盘布局上等同于 AltGr，会与输入字符冲突。

## 视觉与动效

- **界面文字**：`--font-sans`，13px；次要文字 12px；工具行的工作区名称 11px 半粗体。正文只使用 `reading-*` 变量。
- **表面**：侧栏使用 `--surface-panel`；顶栏、编辑区和状态栏使用 `--surface-canvas` / `--reading-bg`；分隔线使用 `--border-subtle`。
- **交互态**：悬停使用 `--surface-subtle`；文件树选中项使用 `--accent-soft`；键盘焦点使用主题包的 `focus-ring` 工具类。主按钮统一使用 `button-primary` 类：静止时背景和边框 `--accent-primary`、文字 `--accent-contrast`，悬停时背景和边框 `--accent-primary-hover`、文字 `--accent-contrast-hover`，按下时背景和边框 `--accent-primary-active`、文字 `--accent-contrast-active`。主题按“填充面 + 对应内容色”成对定义这四个 token，所以两态必须成对切换；开始写作页的“打开文件夹”、对话框的主按钮和恢复对话框的“全部恢复”共用这一处定义。
- **图标**：内联 SVG，取自 Lucide 1.66.0，统一 24×24 网格、`stroke-width="1.75"`、16px 显示尺寸，颜色为 `currentColor`；不引入图标字体或运行时图标库。ISC 许可与 Feather 来源的 MIT 许可见根目录 [THIRD-PARTY-NOTICES.md](../THIRD-PARTY-NOTICES.md)，开发说明见[开发](../development.md#第三方声明)。
- **禁用的效果**：不使用 `backdrop-filter`、窗口 `Vibrancy` 或 `Transparent`，因为它们会增加 GPU 和合成层的开销；不使用常驻的 `will-change`。
- **动效**：只有浮层的出现和消失使用透明度或位移过渡，时长不超过 `--duration-normal`；文件树展开、标签页切换和侧栏显示都没有动画。没有无限循环的动画，“保存中”也是静态的。`prefers-reduced-motion: reduce` 时取消全部过渡。
- **文字缩放**：界面字号乘以 `--mygo-text-scale`（见 MyGo 的无障碍变量），正文字号由阅读层设置决定。

验收：

- **V-1** Paper 和 Ink 下，所有界面文字对其背景的对比度不低于 4.5:1，图标、状态圆点和控件边框不低于 3:1。0.4.0 实测真正的最低值：`--text-muted` 在 `--accent-soft` 上 Paper 5.04:1、Ink 5.73:1；在 `--surface-subtle` 上 Paper 5.17:1、Ink 5.70:1。`--border-strong` 在 `--surface-panel` 上 Paper 3.38:1（Ink 4.07:1）。
- **V-2** 界面 CSS 中没有 `backdrop-filter`、无限循环的 `animation`，也没有常驻的 `will-change`。
- **V-3** 开启“减弱动态效果”后，浮层出现时没有过渡。

## 键盘与无障碍

- 所有可交互元素都能用 Tab 和 ⇧Tab 依次到达，键盘焦点使用主题包的 `focus-ring` 工具类，在 Paper 和 Ink 下都清晰可见。
- 命令面板输入框是焦点环的例外：面板打开期间焦点始终在输入框，焦点环不提供额外信息，因此不使用 `focus-ring` 或浏览器默认 outline，以光标和面板本身表示焦点；`prefers-contrast: more` 下输入行底边改用 `--focus-ring-color`，`forced-colors: active` 下改用 `Highlight` 作为可见兜底。其他控件仍使用 `focus-ring`。
- 文件树使用 `role="tree"` 和 `treeitem`，用方向键移动、展开和折叠，用[快捷键](#快捷键)表“文件树”一类的键位打开、重命名和删除。
- 标签栏使用 `role="tablist"` 和 `tab`，用 ←→ 在标签页之间移动焦点，Enter 或空格切换到该标签页。
- 对话框使用 `role="dialog"` 和 `aria-modal="true"`，打开时焦点进入对话框，Tab 只在对话框内循环（焦点陷阱），关闭后焦点回到打开前的位置。
- 命令面板内的模式切换由面板里的 `sr-only`、`role="status"`、`aria-live="polite"` 状态区域播报“命令模式”“文件模式”或“标题模式”，区域使用 `aria-atomic="true"`，文字取自 `paletteModeLabel`。打开面板时不播报，连续切到同一种模式时再次播报，关闭面板时清空。先清空、短延迟后写入的规则和原因见[命令面板](#命令面板)的“模式播报”。
- 只有图标的按钮（侧栏开关、大纲开关、主题切换、设置按钮等）有 `aria-label`，内容与悬停提示相同。

验收：

- **A-1** 只用键盘，从首次启动完成“打开文件夹 → 在文件树中打开一个文件 → 再打开另一个文件 → 在两个标签页之间切换”，过程中每一步都能看到焦点在哪里。
- **A-2** 用辅助功能检查工具（例如 macOS 的辅助功能检查器）查看：文件树、标签栏和对话框分别报告为 tree、tab list 和 dialog，只有图标的按钮有名称。
- **A-3** 打开任一对话框后连续按 Tab，焦点不会离开对话框；按 Esc 或“取消”关闭后，焦点回到打开前的元素。

## 实现取舍

- **组件**：P0 全部手写，不引入组件库。需要的交互组件只有树、标签页、命令面板、菜单式浮层、弹框和对话框六类，规模可控，而且当前内存已经超出预算。
- **Reka UI**：它是不带样式的 Vue 组件库，可以省下焦点管理、焦点陷阱、方向键导航和 ARIA 属性的工作，但会增加 JS 体积和常驻内存。只有在手写的对话框或弹框无法通过无障碍验收时，才单独引入对应的组件，并在 PR 中附上引入前后的空载内存对比。
- **按需加载**：`pinyin-pro` 等只在命令面板、slash 菜单里用到的依赖，在第一次打开它们时才加载，不进入空载内存。
- **浮层定位**：手写。用 CodeMirror 的 `coordsAtPos` 取锚点，按“下方优先、空间不够翻到上方、限制在窗口内”的规则定位，不引入 Floating UI 一类的库。
- **原生菜单**：右键菜单用原生菜单，外观、键盘操作和平台习惯都由系统负责，也不占页面内存。代价是 macOS 的查询、翻译和拼写建议不会出现在文件树和标签页的菜单里；正文保留 WebView 自带的菜单，不受影响。

## 当前实现（UI-2b-1、UI-2b-2、PR7b-1、PR7b-2、开始写作页）

这一节记录 UI-2b-1、UI-2b-2、PR7b-1、PR7b-2 与开始写作页相关改动的实际范围。后续 PR 完成对应项时，删除这里的临时说明。

- **崩溃恢复**：`Recovery` 服务在 `PathUserData/recovery/` 按路径哈希保存副本，前端在模型变脏后 2 秒写第一份、之后每 5 秒检查，保存失败、混合换行和外部状态暂停时立即写。启动和打开文件夹后显示“发现未保存的内容”对话框，支持全部丢弃、逐个查看、全部恢复；恢复标签通过“这是恢复的内容”横幅在“保留恢复内容”和“使用磁盘版本”之间选择，未选择前暂停该标签的自动保存。用户选择时重新读取磁盘状态；未确认磁盘基线的副本不记录 `diskHash`。单文件副本在恢复时由 Go 重新核对路径并按文件授权一次。
- **多标签**：每个标签页有一个按路径区分的文档模型，编辑器只是活动标签页的视图。切到后台时销毁 `EditorView`，只保留文本、选区（含多选区）、顶部行号与行内偏移、`historyField` 的 JSON；切回时按[后台标签页与恢复](#后台标签页与恢复)恢复。保存、失败恢复、外部状态和换行风格都属于模型，写入始终使用模型自己的路径。
- **标签栏**：活动标签页高亮，同名文件显示上级文件夹名，悬停提示完整相对路径；标签区域横向滚动，活动标签页自动滚动到可见位置。中键、关闭按钮、右键菜单、⌘W 和删除横幅都能关闭标签页；需要处理状态显示圆点，关闭前先确认。关闭最后一个标签页显示占位状态。
- **右键菜单与快捷键**：标签页原生菜单提供关闭、关闭其他、关闭右侧、关闭全部、重新打开关闭的标签页、在文件树中定位、在 Finder 中显示、复制路径和复制相对路径。菜单项在 `src/app/context-menu.ts` 组装，快捷键文字从命令注册表读取；标签栏用 ←→ 移动焦点，Enter 或空格切换。
- **记住标签页**：当前根目录的标签布局、活动标签页、选区和滚动位置保存在用户数据目录的 `tabs.json`；切换文件夹再切回、重启应用时恢复。文件已不存在的标签跳过。撤销历史的范围见[记住标签页](#记住标签页)。单文件标签不写入这个文件。
- **切换文件夹**：先打开原生文件夹选择器，再保存当前根目录的标签页并显示页面对话框，文案为“当前文件夹的 N 个标签页会关闭，切回‘根目录’时会恢复这些标签页”；有保存失败、换行风格混合或未处理的外部状态时列出文件，并把按钮改为“放弃更改并切换”。取消选择不会丢失编辑。
- **启动恢复**：按[启动恢复](#启动恢复)的规则，从最近文件夹的第一项恢复根目录和 `tabs.json` 中的标签页；关闭过工作区时直接显示开始写作页，关闭状态见[设置存储](workspace.md#设置存储)。最近文件夹已不存在时显示“开始写作”，并在该项和标题上方标出。
- **最近打开**：名称胶囊、路径提示、同名后缀、缺失状态和 `ResizeObserver` 分行按[最近打开](#最近打开)实现；分行纯函数在 `src/app/recent-layout.ts`，同名后缀复用 `src/app/tabs.ts` 的 `distinguishingSuffixes`。
- **单文件**：通过“打开方式”或拖入打开的工作区外文件打开为新标签页；切换文件夹时保留，不计入“会关闭”的标签页数量，不随根目录记住，重启后不恢复；关闭标签页时释放 Go 端的文件授权。
- **外部变化**：`Workspace.Watch` 同时驱动文件树刷新和所有工作区标签页的外部修改/删除状态；后台标签页没有视图，直接更新模型并映射选区和顶部行，图片写入产生的 `create` 事件只刷新文件树。外部改名会同步标签页标题和路径，之后的保存使用新路径。
- **占位入口**：大纲开关在开始写作页不显示，有工作区或打开了单文件标签页时按最终位置和外观显示；侧栏的设置按钮和“搜索工作区”入口在有工作区时显示。它们暂时都不可用。大纲属于 PR8，全文搜索视图属于 PR10，设置页属于设置 PR。由于大纲内容尚未实现，L-3 只验证布局不重叠。K-5 的“Windows Ctrl+Shift+L 切大纲而不选中相同文字”在 PR8 完成；目前该键仍是 CodeMirror 的默认行为（选中相同文字）。
- **侧栏工具行**：文件树的根目录行已移除，工作区名称和新建文件、新建文件夹、全部折叠、更多四个图标按钮移到搜索入口下方的 26px 工具行，容器是 `role="group"`、`aria-label="工作区操作"`。新建入口复用文件树的行内输入；全部折叠同时进入命令注册表；更多菜单和空白处右键菜单通过命令注册表执行显示工作区文件夹和关闭工作区。根目录行原先的显示、复制路径和右键菜单位置迁移到空白处菜单，整棵树折叠能力移除。

- **命令面板（PR7b-2）**：`src/components/CommandPalette.vue` 渲染三种模式，模式标识、文件排序和最近文件列表在 `src/app/command-palette.ts`，标题提取在 `src/editor/headings.ts` 供 PR8 复用。命令模式从注册表读取可用且当前可执行的命令，编辑器命令没有活动 Markdown 编辑器时不列出；文件模式每次打开经 `ListFiles()` 读取，最近文件随 `tabs.json` 保存并在删除、改名时清理；标题模式在本次面板会话第一次进入时提取并缓存，大文档超时会在列表末尾提示部分标题未解析，空标题显示“空标题”占位；标题按层级缩进并跳到标题行；活动文档被外部载入或插入改变时面板关闭，执行命令和标题跳转前核对文档版本。拼音仍通过 `loadPinyinMatcher()` 懒加载，命令最近记录继续保存在 `nicole:commands:recent`。打开面板会关闭 slash 菜单、模式菜单和窄窗口浮出的侧栏；对话框打开前只关闭 slash 菜单和模式菜单，浮出侧栏保持打开并使用 `--z-header` 位于对话框之下；面板输入行左右内边距 16px，模式标识独立于查询文字，输入框不使用焦点环；面板使用 `combobox` / `listbox` / `aria-activedescendant`，Tab 留在输入框，点击面板空白处不丢焦点，面板内 ⌘P/⇧⌘P/⇧⌘O 切换模式并保留查询，Esc、遮罩和执行命令都会关闭面板。模式切换通过面板内 `sr-only` 的 `role="status"`、`aria-live="polite"` 区域播报，写入规则见[命令面板](#命令面板)的“模式播报”；打开面板不播报，关闭时随面板移除并取消待写入的计时器。链接弹框属于 PR12，目前没有可关闭的实现。
