# 界面与交互

概要：

- 采用“装订册”布局：隐藏系统标题栏，侧栏从窗口顶部通到底部，放文件树；编辑区上方只有一行顶栏，放标签页、模式切换和大纲开关；大纲在编辑区右侧，默认隐藏；底部是一条细状态栏。
- 文件树按“单窗口多根目录”设计。P0 只允许一个根目录，换文件夹前提醒；P1 放开“添加文件夹”，界面结构不变。
- 文件树显示根目录下的所有文件。Markdown 用 Nicole 编辑，其他文件打开为“无法预览”的占位页。
- 正文里没有浮动工具栏，也没有自定义右键菜单。选中文字后的操作靠快捷键、输入标记字符包裹选区，以及默认关闭的固定格式工具栏。
- 文件树、标签页和根目录有原生右键菜单。
- 所有命令只在[命令注册表](slash-commands.md#命令注册表)里定义一次；本文的快捷键表是默认键位的唯一出处。
- 每项要求都带编号，后续 PR 按编号实现和验收；需要其他文档或后端配合的事项列在[待办](#待办)。

## 原则

- **写作优先**：界面不抢正文的注意力。常驻界面只有顶栏、侧栏和状态栏，其他界面都在用户主动触发时出现。
- **轻量**：空载内存预算见[性能](performance.md#预算)。目前的实测值已经超出预算（见[内存基线](../references/memory-baseline.md)），所以界面设计不增加不必要的常驻开销；每个 PR 的增量按[内存基线的更新约定](performance.md#内存基线的更新约定)记录和判断。
- **主题**：只使用 `@ayingott/theme` 的语义变量、`reading-*` 阅读层和 `src/style.css` 中的 `--nicole-*` 变量，Paper 和 Ink 都必须成立（见[主题与字体](theming.md)）。字体全部用系统字体。
- **文本规则**：菜单、按钮、标签和状态文字的末尾不加额外符号，例如写“打开文件夹”，不写“打开文件夹…”；写“保存中”，不写“保存中…”。快捷键放在单独的一列，颜色用 `--text-muted`；下拉用图标表示，不在文字后加 `▾` 之类的字符。
- **平台**：以 macOS 为先，Windows 和 Linux 上布局同样成立。不同平台的文字差异只在本文明确列出的地方出现，例如“在 Finder 中显示”。

验收：

- **P-1** Nicole 自己写的菜单、按钮和状态文字都不以 `…`、`...`、`:`、`：`、`▾`、`›`、`>` 结尾；成对引号的后半个（例如对话框标题 切换到“博客” 末尾的 `”`）不算。MyGo 和更新插件自带的文字（例如“检查更新…”）不在此列。
- **P-2** 界面 CSS 只引用主题包的语义变量、`reading-*` 阅读层变量和 `--nicole-*` 变量，不写死颜色值。窗口控制按钮之类的平台元素除外。
- **P-3** 每个界面 PR 满足[内存基线的更新约定](performance.md#内存基线的更新约定)。

## 窗口与标题栏

- 窗口使用 MyGo 的隐藏标题栏：`TitleBarStyle: mygo.TitleBarHidden`。`TitleBarHeight: 40` 只对 Windows 和 Linux 生效；macOS 上用 `TrafficLightPosition` 让红绿灯在 40px 内垂直居中（MyGo 按“按钮高度 + 2 × Y”计算标题栏高度，Y 取使结果等于 40 的值，X 与侧栏左边距对齐）。页面绘制的顶部区域固定为 40px，不随 `--mygo-titlebar-height` 变化（全屏时该变量为 `0px`）；MyGo 的变量只用 `--mygo-titlebar-inset-left`、`--mygo-titlebar-inset-right` 来让出左右两侧窗口控制按钮的位置。
- macOS 的红绿灯在左上角，叠在侧栏顶部；侧栏隐藏时，顶栏左侧留出 `--mygo-titlebar-inset-left`。Windows 的最小化、最大化、关闭按钮在右上角，顶栏右侧留出 `--mygo-titlebar-inset-right`。Linux 按桌面环境给出的两个变量留白。全屏时左右两个变量为 `0px`，顶栏内容随之贴到左右边缘，高度仍是 40px。
- 顶栏和侧栏顶部的空白处标记为 `--app-region: drag`，可以拖动窗口。MyGo 只自动排除按钮、输入框、链接等原生可交互元素，自绘的标签页、模式切换分段等元素要显式标记 `--app-region: no-drag`。双击拖动区域时按系统行为缩放或最大化窗口。
- 菜单栏：macOS 使用 `main.go` 设置的应用菜单。Windows 隐藏标题栏后没有菜单栏位置，按 Alt 或 F10 时 MyGo 在左上角弹出菜单。Linux 默认隐藏菜单栏，按 Alt 或 F10 时显示。
- 菜单项的快捷键不能与[快捷键](#快捷键)表冲突，也不能提供会丢失页面状态的操作。MyGo 默认的“显示”菜单（`RoleViewMenu`）包含“重新载入”⌘R、“强制重新载入”⇧⌘R，默认的“窗口”菜单（`RoleWindowMenu`）在 Windows 和 Linux 上把 Ctrl+W 绑定到关闭窗口，这些都要去掉或替换；“显示”菜单中的“切换开发者工具”（⌥⌘I、Ctrl+Shift+I）只在开发构建中保留；缩放（⌘+、⌘-、⌘0）和全屏保留。
- 应用主题与系统外观不同时，用 `mygo.Theme.SetSource` 同步，让原生菜单、右键菜单和对话框跟随应用主题。
- MyGo 0.7.3 的 `RoleUndo`/`RoleRedo` 在 macOS 上使用 AppKit 的 `undo:`/`redo:` selector，不会进入 CodeMirror 的历史。这两个菜单项改为向页面发送 `nicole:edit-command`，由页面执行 CodeMirror 的历史命令；输入法组合期间（`EditorView.compositionStarted`）忽略该命令。macOS 上已实测菜单点击、⌘Z 和 ⇧⌘Z 都作用于 CodeMirror 的历史，组合期间的忽略也有 Vitest 覆盖。Windows 和 Linux 的菜单事件行为**待实测**，见[待办](#待办)。
- 窗口启动时在光标所在的屏幕上居中，尺寸沿用上次保存的大小；规则和实现见[工作区与文件](workspace.md#窗口位置)（已由 #8 实现）。

验收：

- **W-1** 在 macOS、Windows 和 Linux 上，顶栏、标签页、模式切换和大纲开关都不被窗口控制按钮遮挡，全屏和退出全屏后也一样。
- **W-2** 进入全屏和退出全屏后，顶栏高度都是 40px。
- **W-3** 拖动顶栏空白处和侧栏顶部空白处都能移动窗口；拖动标签页不会移动窗口。
- **W-4** 系统为亮色、应用切到暗色后，右键菜单和原生对话框显示为暗色，反过来也一样。
- **W-5** 启动后窗口出现在光标所在的屏幕中央，尺寸与上次退出时一致。

## 整体布局

```text
+-----------+---------------------------------------------+
| A       B | C                                         D |
|           +---------------------------------------------+
| E         | F                                           |
|           +-------------------------------+-------------+
| G         | H                             | I           |
|           |                               |             |
| J       K +-------------------------------+-------------+
|           | L                                           |
+-----------+---------------------------------------------+
```

A 红绿灯（macOS）　B 隐藏侧栏　C 标签页　D 模式切换与大纲开关　E 搜索全部文件夹　F 格式工具栏（默认关闭）　G 根目录与文件树　H 正文　I 大纲（默认隐藏）　J 打开文件夹　K 设置　L 状态栏

| 区域 | 尺寸 | 显示与隐藏 |
|---|---|---|
| 侧栏 | 默认 252px，可拖动右边缘在 200–400px 之间调整，双击边缘恢复默认；宽度全局记住 | ⌃⌘S 或侧栏顶部的按钮切换；隐藏后顶栏左侧出现显示侧栏的按钮 |
| 顶栏 | 固定高 40px，位于编辑区上方，左边与侧栏右边缘对齐 | 始终显示 |
| 格式工具栏 | 高 36px，在顶栏下方 | 默认关闭，见[固定格式工具栏](#固定格式工具栏) |
| 编辑区 | 填满剩余空间；正文最大宽度为 `--reading-measure`，在编辑区（不含大纲）内水平居中 | 有活动标签页时显示；否则显示[占位状态](#空状态) |
| 大纲 | 宽 220px，在编辑区右侧，位于顶栏（或格式工具栏）与状态栏之间 | 默认隐藏；顶栏最右的大纲开关或 ⌃⌘O 切换，开关全局记住，见[大纲](#大纲) |
| 状态栏 | 高 26px，只在编辑区下方，不延伸到侧栏 | 始终显示 |

窗口宽度变化时：

| 窗口宽度 | 侧栏 | 顶栏 | 格式工具栏 |
|---|---|---|---|
| ≥ 960px | 固定在左侧，占据布局 | 标签页按需收缩 | 全部按钮 |
| 760–959px | 默认隐藏；打开时浮在编辑区上方，带阴影，不挤压正文；选择文件、按 Esc 或点击外部后收起 | 同上 | 放不下的按钮收进“更多”按钮的菜单 |
| 640–759px | 同上 | 模式切换收成一个图标按钮，点击后弹出三种模式 | 同上 |

大纲按侧栏右侧整块区域（下称内容区）的宽度决定位置，与侧栏是否显示无关：内容区宽度不小于 840px 时，大纲固定在右侧，占据布局；小于 840px 时，打开的大纲浮在内容区右上角，带阴影，不挤压正文。内容区为 840px 时，固定大纲后正文区域约 620px，扣除左右各 2rem 的内边距后约 556px，比 `--reading-measure` 窄，但按 18px 的正文字号每行仍能放下约 30 个汉字；默认窗口 1100px 减去侧栏 252px 后为 848px，大纲可以固定显示。

窗口最小尺寸为 640×480，由 `main.go` 限制。

验收：

- **L-1** 窗口宽度不小于 960px 时，侧栏与编辑区并排；拖动侧栏边缘可以在 200–400px 之间调整，重启后宽度保持。
- **L-2** 窗口宽度在 640–959px 之间时，打开侧栏不会改变正文的宽度和位置；按 Esc 或打开文件后侧栏收起。
- **L-3** 窗口最小时，顶栏的标签页、模式切换和大纲开关都可用，不换行，不互相重叠。
- **L-4** 隐藏侧栏后，正文仍水平居中，宽度不超过 `--reading-measure`。

## 侧栏

### 结构

从上到下：

1. 顶部 40px：拖动区域，右侧是隐藏侧栏的按钮。macOS 上红绿灯位于左侧。
2. “搜索全部文件夹”入口，右侧用浅色标出 ⇧⌘F。点击后侧栏切换为[全文搜索](#全文搜索)。
3. 根目录分组：每个根目录一个分组标题，下面是它的文件树。
4. 底部一行：左侧是“打开文件夹”（P1 为“添加文件夹”），右侧是设置按钮（齿轮图标，悬停提示“设置 ⌘,”），点击打开[设置](#设置)。

### 根目录

- 分组标题显示文件夹名，12px 半粗体。分组折叠时，在名字后面用浅色显示路径，主目录写成 `~`。鼠标悬停时右侧出现“新建文件”按钮。
- **P0**：只有一个根目录。点击底部的“打开文件夹”或按 ⌘O 选择另一个文件夹时，替换当前根目录，替换前提醒，见[切换文件夹](#切换文件夹)。
- **P1**：可以添加多个根目录，按添加顺序排列；“从侧栏移除”只移除显示，不删除文件。界面结构与 P0 相同，只是底部按钮从“打开文件夹”变成“添加文件夹”，切换提醒不再出现。
- 每个根目录的 `assets/` 和 `.nicole/` 只对这个根目录里的文件生效：粘贴的图片存到当前文件所在根目录的 `assets/`。
- 启动时恢复上次的根目录、标签页和活动标签页。上次的根目录已经不存在时，显示[未打开文件夹](#空状态)的状态，并在最近列表中把它标为“已不存在”。

### 文件树

- 显示根目录下的所有文件和文件夹，包括空文件夹，带扩展名。`.md` 文件用 `--text-secondary`，其他文件用 `--text-muted`。
- 默认不显示：`.git`、`.DS_Store`、`Thumbs.db`、`desktop.ini`，以及 Nicole 写入时产生的临时文件（命名规则见[写入保证](workspace.md#写入保证)）。
- 以 `.` 开头的其他文件和文件夹（例如 `.nicole/`）照常显示，颜色为 `--text-muted`。
- `node_modules` 显示为 `--text-muted` 并保持折叠，展开时才读取内容。
- **按需读取**：打开根目录时只读取第一层；文件夹第一次展开时才读取它的下一层。全文搜索和链接补全仍各自扫描 `.md` 文件，沿用[列文件规则](workspace.md#列文件规则)中跳过隐藏目录和 `node_modules` 的规则。
- **排序**：文件夹在前，文件在后；同类按 `Intl.Collator("zh-Hans-CN", { numeric: true })` 排序，例如“第2章”排在“第10章”前面。
- **展开状态**：按根目录记在用户数据目录，不写进工作区。打开文件时自动展开它所在的各级文件夹，并把它滚动到可见位置。
- **单击**：`.md` 文件已经打开时切换到它的标签页，否则在活动标签页右侧新开一个；其他文件打开[无法预览的占位页](#非-markdown-文件)。不提供临时预览标签页。
- **键盘**：方向键移动、展开和折叠；重命名、打开、移到废纸篓和新建文件夹的键位见[快捷键](#快捷键)表的“文件树”一类，与各平台文件管理器的习惯一致。
- **新建**：在目标文件夹中出现一个行内输入框，默认名称为“未命名.md”，并预先选中“未命名”。输入的名称没有扩展名时，自动补上 `.md`。
- **重命名**：行内编辑，预先选中不含扩展名的部分。已打开的文件重命名后，标签页标题和路径同步更新。自动更新引用属于 P1（见[产品范围](product.md#p1)）。
- **外部变化**：文件监听到新增、删除和改名后，文件树在 1 秒内更新，展开状态和选中项保持不变。监听范围见[文件监听](workspace.md#文件监听)：隐藏目录（例如 `.nicole/`）和 `node_modules` 不监听，里面的变化在下次展开该目录时刷新。
- **后缀显示**：受[设置](#设置)中“隐藏 .md 后缀”控制，默认显示后缀。

### 全文搜索

- 点击“搜索全部文件夹”或按 ⇧⌘F，侧栏切换为搜索视图：顶部是输入框（带区分大小写和正则开关），下面是结果。按 Esc 或清空输入框后回到文件树。
- 结果按根目录、文件、匹配行三级分组，匹配行最多显示一行上下文，匹配部分高亮。P0 只有一个根目录时，不显示根目录这一级。
- 结果通过 Channel 流式到达，边搜边显示；搜索进行中时，在结果上方显示“正在搜索”，完成后显示“3 个文件中有 5 处结果”。超过 1000 处时停止显示，并提示“结果过多，请缩小范围”。
- 点击匹配行时打开文件，选中匹配文字，并滚动到可见区域中部。
- 只搜索 `.md` 文件，见[工作区与文件](workspace.md#搜索)。

验收：

- **S-1** 打开一个包含 `node_modules`（超过 10 万个文件）的文件夹，文件树在 1 秒内显示第一层；展开 `node_modules` 之前不读取它的内容。
- **S-2** 文件树显示 `.md`、图片、PDF 和空文件夹，不显示 `.git`、`.DS_Store` 和 Nicole 的临时文件。
- **S-3** “第2章.md”排在“第10章.md”前面，文件夹排在文件前面。
- **S-4** 在监听范围内（不含隐藏目录和 `node_modules`）从外部新建、删除、改名文件，包括非 `.md` 文件，文件树在 1 秒内更新，原来的展开状态和选中项不变。
- **S-5** 全文搜索的结果边搜边出现；点击结果后打开文件并选中匹配文字。
- **S-6** P0 中，打开另一个文件夹会替换当前根目录；侧栏结构与多根目录时一致，只是只有一个分组。

## 标签页

### 外观与行为

- 标签页在顶栏里，高 28px，最小宽度 96px，最大宽度 200px。活动标签页使用 `--surface-subtle` 背景和 `--text-primary` 文字；其他标签页使用 `--text-muted`。
- 标题是文件名，后缀是否显示与文件树一致。标题超长时用 CSS 截断。悬停时提示“根目录名/相对路径”。
- 同名文件：多个标签页的文件名相同时，在文件名后用 11px 的 `--text-muted` 显示区分信息。不同根目录显示根目录名，例如“README.md 博客”；同一根目录显示上一级文件夹名。
- 关闭按钮只在活动标签页和鼠标悬停时显示。鼠标中键点击可以关闭标签页。
- 关闭处于保存失败、换行风格混合或文件已被删除状态的标签页时，不论用 ⌘W、中键、关闭按钮、右键菜单还是删除横幅上的“关闭标签页”按钮，都先显示确认对话框，按钮为“取消”和“放弃更改并关闭”。
- 自动保存是常态，所以普通的“编辑中”和“保存中”不在标签页上标示，只显示在[状态栏](#状态栏)。只有下列需要用户处理的状态，才在关闭按钮的位置显示一个圆点，并在悬停时说明原因：保存失败（`--status-danger-fg`）、换行风格混合（`--status-warning-fg`）、文件已在磁盘上被删除（`--status-danger-fg`）。
- 新标签页打开在活动标签页的右侧。标签页超出顶栏宽度后，在标签区域内横向滚动；切换标签页时，活动标签页自动滚动到可见位置。拖动排序属于 P1。
- 关闭最后一个标签页后，编辑区显示[占位状态](#空状态)。

### 后台标签页与恢复

[性能规格](performance.md#控制内存的手段)要求后台标签页只保留文本、销毁编辑器视图。切回时要恢复到离开前的样子：

| 保存的内容 | 恢复方式 |
|---|---|
| 文本 | 用它创建新的 `EditorView` |
| 选区，包括多选区 | 创建时作为初始选区 |
| 滚动位置 | 记录可见区域顶部那一行的行号和行内偏移；新视图完成第一次测量后，把这一行滚动回同样的偏移 |
| 撤销历史 | 用 `EditorState.toJSON` 序列化 `historyField`，切回时恢复；沿用 CodeMirror 默认的 `minDepth: 100`，不放大。后台标签页的这部分占用计入[性能](performance.md#预算)中“打开 10 篇文档”的场景 |
| 查找条件 | 全局共享，不按标签页保存 |

编辑模式是全局的，切回的标签页使用当前模式。

### 非 Markdown 文件

- 在文件树中点击非 `.md` 文件时，打开一个占位标签页：页面中间是文件类型示意图，下面写“无法预览此类型的文件”，再下一行用浅色显示“文件名 · 大小 · 所在文件夹”，最下方是“用默认应用打开”和“在 Finder 中显示”两个按钮。
- 占位页不创建编辑器。状态栏左侧为空，不显示字数，也不显示保存状态。
- 以后在应用内预览图片时，替换这个占位页；布局和入口不变。

### 记住标签页

- 每个根目录各自记住打开的标签页、活动标签页，以及每个标签页的选区和滚动位置，保存在用户数据目录。
- P0 切换文件夹后再切回来，以及重启应用时，都恢复这些标签页。

验收：

- **T-1** 在标签页 A 选中一段文字并滚动到中间，切到标签页 B 再切回 A：选区相同；窗口尺寸不变时，可见区域顶部是同一行；⌘Z 能撤销切换之前的输入。
- **T-2** 后台标签页没有 `EditorView` 实例，DOM 中只有一个 `.cm-editor`。
- **T-3** 同一个根目录下，`随笔/README.md` 和 `旅行/README.md` 同时打开时，两个标签页分别显示“README.md 随笔”和“README.md 旅行”。（P1）两个根目录下各有一个 `README.md` 时，分别显示根目录名，例如“README.md 博客”和“README.md 写作”。
- **T-4** 连续输入时，标签页上不出现闪烁的圆点；让保存失败后，活动标签页出现红点，悬停时说明原因。
- **T-5** 打开 15 个标签页后，标签区域可以横向滚动，活动标签页始终可见，顶栏右侧的模式切换不被挤出窗口。
- **T-6** 点击 PNG 文件时打开占位页；“用默认应用打开”调用系统默认应用；“在 Finder 中显示”在 Finder 中选中该文件。
- **T-7** 重启应用后，上次打开的标签页、活动标签页、选区和滚动位置都恢复。
- **T-8** 让一个标签页保存失败，然后分别用 ⌘W、鼠标中键、关闭按钮和右键菜单中的“关闭”关闭它：每次都先出现确认；选择“取消”后标签页和内容都保留。从外部删除一个已打开的文件后，点击删除横幅上的“关闭标签页”，同样先出现确认。

## 编辑区

### 模式切换

- 顶栏右侧有一个三段式切换，文字为“预览”“沉浸”“源码”；悬停时显示完整名称和快捷键，例如“实时预览 ⌃⌘1”。
- 当前模式的分段使用 `--surface-subtle` 背景和 `--text-primary` 文字。切换模式不重建 `EditorView`（见[编辑模式](editor-modes.md#单一编辑器内核)）。
- 正文排版完全由 `reading-*` 变量决定，与模式切换控件无关。
- 模式切换的右边是顶栏最右的大纲开关，见[大纲](#大纲)。顶栏不放命令面板按钮，命令面板只通过快捷键打开。

### 大纲

大纲放在编辑区右侧，而不是左侧：

- 左侧已经有侧栏，两列导航挤在同一边，会把正文推离窗口中央。
- 放在右侧与侧栏左右对称，大纲开关在顶栏最右，与侧栏开关在左上角相对应。
- 正文在宽窗口中居中，右侧本来就有留白，大纲占用的主要是这块空间。

规则：

- 默认隐藏。顶栏最右的大纲开关（图标按钮，悬停提示“显示或隐藏大纲 ⌃⌘O”）、⌃⌘O 和命令面板都可以切换；开关状态全局记住。显示时开关按钮使用 `--surface-subtle` 背景。
- 内容区宽度不小于 840px 时，大纲固定在右侧，宽 220px，背景与编辑区相同，没有边框；正文在剩下的宽度内居中。
- 内容区宽度小于 840px 时，大纲不会自动出现；点击大纲开关后，它临时浮在内容区右上角（顶栏下方 8px、右边 8px），高度随内容变化，最多到状态栏上方，使用浮层外观。点击其中的标题后自动收起，按 Esc 或点击外部也会收起。临时打开和收起不改变记住的开关状态。
- 顶部是 12px 半粗体的标题“大纲”，下面是当前文件的标题列表；只显示活动标签页的大纲。活动标签页不是 Markdown 文件或没有标签页时，大纲开关不可用，固定的大纲区域也不显示。
- 显示 H1–H3，按级别缩进。frontmatter 之后的第一个非空行是 H1、而且全文只有这一个 H1 时，它通常就是文章标题，不在大纲中显示。文档没有标题时，显示“没有标题”。
- 当前所在章节，即包含编辑区可见范围顶部那一行的标题，用 `--surface-subtle` 背景加左侧 2px 的 `--text-accent` 竖线标出，随滚动更新。
- 点击标题时，编辑区滚动到该标题，标题距可见区域顶部 24px，光标移到标题行的开头，焦点回到编辑区。
- 大纲在文档变化停止 300ms 后更新；中文输入法组合输入期间不更新。
- 不显示大纲时，可以用 ⇧⌘O（转到标题）按标题跳转，见[命令面板](#命令面板)。

### 选中文字后的操作

正文里不提供浮动工具栏，也不提供自定义右键菜单。选中文字后，可以这样操作：

1. **格式快捷键**：见[快捷键](#快捷键)。
2. **输入标记字符包裹选区**：规则见下表。
3. **固定格式工具栏**：默认关闭，见[固定格式工具栏](#固定格式工具栏)。
4. **命令面板**：打开命令面板时保留选区，执行的命令作用于选区。

选中文字后按 `/` 时替换选区，不打开 slash 菜单（见[Slash 命令](slash-commands.md#触发与开关)）。

**包裹规则**：只有下面五个条件同时满足时，输入的字符才会包裹选区；任何一条不满足，都像普通编辑器一样用输入的内容替换选区，不补出配对的括号或引号。

| # | 条件 | 不满足的例子 |
|---|---|---|
| 1 | 每个选区都不为空，而且都在同一行内 | 选区跨越多行或多个段落 |
| 2 | 输入的是半角字符 `*`、`` ` ``、`~`、`[` 之一 | 中文输入法输出的 `×`、`·`、`～`、`【`；`_`、`(`、`{`、`'`、`"`、`《` 等其他字符 |
| 3 | 字符来自直接按键 | 输入法组合中或上屏、粘贴、拖放、自动补全 |
| 4 | 选区完全位于普通正文中 | 选区在代码块、行内代码、frontmatter 或 HTML 块中 |
| 5 | 选区去掉首尾空白后仍不为空 | 只选中了空格 |

包裹后的结果：

- 选区首尾的空白留在标记外面，例如选中 ` 文字 ` 后输入 `*`，得到 ` *文字* `。
- 包裹后选区仍是原来的文字，不包括标记，所以连按两次 `*` 先得到斜体，再得到加粗；连按两次 `` ` `` 得到两层反引号，与 Markdown 的行内代码写法一致。
- `~` 一次就包成 `~~文字~~`，因为编辑器使用的 GFM 解析只把成对的 `~~` 识别为删除线；选区两侧已经是 `~~` 时，再输入 `~` 不做任何事。
- `[` 把选区变成 `[文字]()`：实时预览和源码模式下，光标停在括号里；沉浸模式下打开[链接弹框](#链接与图片弹框)。
- 一次 ⌘Z 撤销整个包裹。
- 输入字符只会添加标记，不会去掉标记；去掉格式用快捷键切换，例如再按一次 ⌘B。
- 三种模式下行为相同；沉浸模式下包裹后，标记照常隐藏。

与编辑器自带的括号自动配对（`basicSetup` 中的 `closeBrackets`）的关系：只要任一选区不为空，这一次输入就全部由 Nicole 按上面的规则处理，`closeBrackets` 不参与；多光标中有的选区为空时，不满足条件 1，不包裹，非空选区被替换，空选区处只插入输入的字符，也不补出配对。所有选区都为空时，`closeBrackets` 照常补出配对的括号和引号。处理包裹的输入处理器优先级高于 `closeBrackets`，因此有选区时输入 `[` 只会得到上面规定的结果。

不包括 `_`：CommonMark 不把夹在文字中间的 `_` 当作强调标记，而中文句子里的选区两侧几乎总是文字，用 `_` 包裹后大多不会渲染成斜体。另外，选区以标点开头或结尾、外侧又紧挨文字时（例如选中“工具”连同引号），按 CommonMark 规则 `*` 也可能不被识别为强调；这是 Markdown 语法本身的限制，Nicole 不为此改写选区或原文。

### 固定格式工具栏

- 位于顶栏下方，高 36px，横跨编辑区，按钮在编辑区内水平居中，下边有一条 `--border-subtle` 分隔线。工具栏的位置固定，不跟随选区。
- 默认关闭；在[设置](#设置)中，或在命令面板中执行“显示格式工具栏”“隐藏格式工具栏”来切换。开关全局记住。
- 按钮分三组，组之间有分隔线：
  - 加粗、斜体、删除线、行内代码、链接；
  - 段落类型下拉（正文、标题 1–3）、无序列表、有序列表、任务项、引用、代码块；
  - 表格、图片。
- 按钮的图标、名称和快捷键都从命令注册表读取；悬停提示为“名称 快捷键”，例如“加粗 ⌘B”。
- 按钮作用于当前选区；没有选区时作用于光标位置。点击按钮不让编辑器失去焦点，选区保持不变。
- 光标所在位置已经有某种格式时，对应按钮高亮（`--accent-soft` 背景），例如光标在加粗文字里时，“加粗”高亮。只在选区变化时检查一次语法树。
- 中文输入法组合期间，所有按钮暂时不可用。
- 三种模式下都可用。窗口窄时，放不下的按钮收进末尾的“更多”菜单。

### 链接与图片弹框

- 弹框锚定在链接或图片元素下方，空间不够时翻到上方。弹框宽 340px。
- 链接弹框有“文本”和“链接”两个输入框，以及“移除链接”“打开”“完成”三个按钮。Enter 等同于“完成”，Esc 取消修改并关闭。如果这个链接是刚刚用 ⌘K 或输入 `[` 新建的，按 Esc 时撤销这次插入（作为一个撤销步），不留下空的 `[文字]()`。
- 图片弹框有“替代文本”和“路径”两个输入框，以及“在 Finder 中显示”“完成”两个按钮。
- **打开方式**：任何模式下，按 ⌘K 都会打开链接弹框；没有选区时插入一个新链接。沉浸模式下，点击链接或图片会显示弹框，但焦点仍在正文；按 Tab 进入弹框。实时预览和源码模式下能看到 URL，所以只有 ⌘K 会打开弹框。三种模式下，⌘ 加点击（Windows 和 Linux 为 Ctrl 加点击）链接时只用浏览器打开链接，不增加选区；在链接以外的位置，⌘ 加点击仍是 CodeMirror 的“增加一个选区”（`clickAddsSelectionRange`）。

### 任务框

任务框按 #6 的实现自绘：外框、背景和勾选标记都由 CSS 绘制，读取 `--nicole-checkbox-*` 变量（见[编辑模式](editor-modes.md#当前实现)）。视觉要求如下：

| 部位 | 变量 | 取值 | Paper 对比度 | Ink 对比度 |
|---|---|---|---|---|
| 未勾选的外框 | `--nicole-checkbox-border` | `var(--text-muted)` | 5.67:1（对 `--surface-canvas`） | 7.16:1 |
| 未勾选的背景 | `--nicole-checkbox-bg` | `transparent` | — | — |
| 勾选后的外框与背景 | `--nicole-checkbox-checked-border`、`--nicole-checkbox-checked-bg` | `var(--text-accent)` | 5.85:1 | 10.27:1 |
| 勾选标记 | `--nicole-checkbox-mark` | `var(--surface-canvas)` | 5.85:1（对勾选背景） | 10.27:1 |
| 键盘焦点 | `--nicole-checkbox-focus` | `var(--reading-focus)` | — | — |

- 已完成任务的文字不加删除线，保持正文颜色，避免改变用户对原文的观感。
- 任务框的尺寸、圆角、外框宽度和勾选标记的形状沿用 #6 的实现：1em 见方，圆角 3px，外框 1.5px。

目前 `main` 上没有设置这些变量，回退值不满足要求：Paper 下未勾选外框的对比度为 1.79:1，勾选背景（`--accent-primary`）为 2.7:1；Ink 下未勾选外框为 2.5:1。需要在 `src/style.css` 中补上上表的值，见[待办](#待办)。

验收：

- **E-1** 大纲默认隐藏；点击顶栏最右的大纲开关后，大纲出现在编辑区右侧，重启后保持打开。内容区宽度小于 840px 时，大纲不自动出现；点击开关后浮在正文上方，不改变正文的宽度和位置，收起后不改变记住的开关状态。
- **E-2** 滚动正文时，大纲中当前章节的高亮随之变化；点击大纲中的标题后，焦点回到编辑区，光标位于标题开头。
- **E-3** 中文输入法组合期间，大纲不闪烁、不重排。
- **E-4** 选中“什么样的工具”后输入 `*` 两次，得到 `**什么样的工具**`，选区仍是“什么样的工具”；按一次 ⌘Z 回到 `*什么样的工具*`。
- **E-5** 选中跨两行的文字后输入 `*`，选区被替换为 `*`。
- **E-6** 选中“已经废弃的写法”后输入一次 `~`，得到 `~~已经废弃的写法~~`，并渲染为删除线。
- **E-7** 中文输入法开启时，选中文字后按 `` ` `` 键，选区被替换为 `·`，不包裹。
- **E-8** 在代码块中选中文字后输入 `*`，选区被替换。
- **E-9** 选中正文中的文字后输入 `(`，选区被替换为单个 `(`，不变成 `(文字)`。
- **E-10** 在代码块中选中文字后输入 `[`，选区被替换为单个 `[`，不变成 `[文字]` 或 `[文字]()`。
- **E-11** 选中文字后输入 `/`，选区被替换为 `/`，不打开 slash 菜单。
- **E-12** 格式工具栏默认不显示；打开后，点击“加粗”不让编辑器失去焦点，选区保持不变；光标在加粗文字中时，“加粗”按钮高亮。
- **E-13** 沉浸模式下点击链接时显示链接弹框，焦点仍在正文，可以继续输入；按 Tab 后焦点进入弹框。
- **E-14** ⌘ 加点击链接时，链接在浏览器中打开，编辑器里的选区数量不变；⌘ 加点击普通文字时，增加一个选区。
- **E-15** 沉浸模式下选中文字后输入 `[` 打开链接弹框，直接按 Esc：文字恢复原样，没有 `[文字]()`。
- **E-16** 在三种模式下分别在没有选区时按 ⌘K 新建链接，再按 Esc：文档恢复到按 ⌘K 之前的样子。
- **E-17** 任务框在 Paper 和 Ink 下，未勾选外框和勾选背景对 `--surface-canvas` 的对比度都不低于 3:1，勾选标记对勾选背景不低于 3:1。
- **E-18** 正文中右键时，不出现应用自己添加的菜单项。

## 状态与提示

### 空状态

| 状态 | 侧栏 | 编辑区 |
|---|---|---|
| 未打开文件夹（首次启动，或上次的文件夹已不存在） | 隐藏 | 居中显示标题“开始写作”，说明“打开一个文件夹作为工作区，里面的文件就是你的文章”，主按钮“打开文件夹”（右侧用浅色标出 ⌘O），下方是最近打开的文件夹列表，最多 10 个，每项显示名称和路径；已不存在的项写“已不存在”，悬停时可以移除 |
| 文件夹是空的 | 显示根目录分组，分组下写“这个文件夹是空的”，以及“新建文件”按钮 | 同下一行 |
| 已打开文件夹，没有打开的标签页 | 正常显示 | 居中显示“选择一个文件开始写作”，下面用浅色列出“新建文件 ⌘N”“快速打开 ⌘P” |

上次的文件夹已不存在时，在“开始写作”标题上方加一行说明，例如：上次打开的文件夹“写作”已不存在。

### 保存状态

保存行为由[工作区与文件](workspace.md#保存)定义，这里只规定显示：

| 状态 | 状态栏 | 其他提示 |
|---|---|---|
| 编辑中（等待自动保存） | 圆点 `--text-muted`，文字“编辑中” | 无 |
| 保存中 | 圆点 `--text-muted`，文字“保存中”；只在保存超过 300ms 时显示，避免闪烁 | 无 |
| 已保存 | 圆点 `--status-success-fg`，文字“已保存” | 无 |
| 保存失败 | 圆点和文字都用 `--status-danger-fg`，文字“保存失败” | 编辑区顶部横幅，`--status-danger-*` 配色：“无法保存：原因”，按钮“重试”；标签页显示红点。横幅在下一次保存成功后消失 |
| 换行风格混合 | 圆点 `--status-warning-fg`，文字“换行风格混合，未自动保存” | 编辑区顶部横幅，`--status-warning-*` 配色，说明切换或关闭时可以放弃更改；标签页显示黄点 |

保存失败时不自动重试（见[写入保证](workspace.md#写入保证)）。用户继续输入会触发下一次自动保存；“重试”立即保存一次。

### 外部修改与删除

- **外部修改，本地没有待保存内容**：直接载入磁盘上的新内容。载入时按新旧文本的差异生成一次修改，把选区映射到新内容上；载入前可见区域顶部那一行的开头也按同一次修改映射到新内容，滚动后这一行回到原来的行内偏移；这一行被删除时，映射到删除位置之后最近的一行。载入后在状态栏短暂显示“已载入磁盘上的新内容”，3 秒后恢复为保存状态。Nicole 自己写入引起的变化不触发这个提示。
- **外部修改，本地有待保存内容或保存失败**：暂停这个标签页的自动保存，编辑区顶部显示横幅：“此文件已在 Nicole 之外被修改”，按钮为“载入磁盘版本”和“保留我的版本”。选择“保留我的版本”后，下一次保存覆盖磁盘内容。
- **外部删除或移走**：暂停这个标签页的自动保存，横幅为“此文件已在磁盘上被删除或移走，内容仍保留在这个标签页中”，按钮为“重新保存”和“关闭标签页”。标签页显示红点。
- **根目录不可用**（例如移动硬盘被拔出）：根目录分组标题后显示“不可用”，这个根目录下的标签页显示删除横幅。

横幅位于顶栏（或格式工具栏）下方、正文上方，横跨编辑区，高度随文字变化。同一时间每个标签页最多显示一条横幅，优先级从高到低为：外部删除、外部修改、保存失败、这是恢复的内容（见[崩溃恢复](#崩溃恢复)）、换行风格混合、这个文件不在已打开的文件夹中（见[打开工作区之外的文件](#打开工作区之外的文件)）。高优先级的横幅处理完后，显示下一条仍然成立的横幅。

### 崩溃恢复

- 启动时如果发现恢复副本（见[工作区与文件](workspace.md#崩溃恢复)），在窗口中央显示模态对话框：标题“发现未保存的内容”，说明“Nicole 上次没有正常退出，以下文件有比磁盘更新的内容”，下面列出文件名、副本时间和字数差，例如“今天 23:41 · 多 186 字”。
- 按钮：“全部丢弃”（`--status-danger-fg` 文字）、“逐个查看”、“全部恢复”（主按钮）。
- “全部恢复”：把每个副本作为待保存内容载入对应的标签页，由自动保存写回磁盘。
- “逐个查看”：依次打开这些标签页，每个标签页显示横幅“这是恢复的内容”，按钮为“保留恢复内容”和“使用磁盘版本”。
- 对话框关闭之前，不在后台自动写入这些文件。

### 切换文件夹

仅适用于 P0（只有一个根目录）：

- 选择另一个文件夹前，显示确认对话框。以切换到“博客”为例：标题为：切换到“博客”；说明为：当前文件夹的 5 个标签页会关闭，切回“写作”时会恢复这些标签页；按钮为“取消”和“切换”。
- 有保存失败或换行风格混合的标签页时，对话框列出这些文件，按钮改为“取消”和“放弃更改并切换”。
- 这个页面对话框代替当前实现中切换文件夹前调用的 `ConfirmDiscard()`（见[保存](workspace.md#保存)），同一次切换不再弹出原生确认框。多标签页界面中切换文件只是切换标签页，内容保留在标签页里，不需要确认。批量关闭标签页的确认同样用页面对话框，见[右键菜单](#右键菜单)。

### 打开工作区之外的文件

通过文件关联打开一个 `.md` 文件，或把它拖到标签栏上时：

1. 文件在当前根目录里：打开它，并在文件树中定位。
2. 文件在最近用过的某个文件夹里：P0 走[切换文件夹](#切换文件夹)的确认；P1 直接添加该文件夹并打开文件。
3. 都不是：显示对话框“这个文件不在已打开的文件夹中”，按钮为“只打开这个文件”“打开所在文件夹”（P1 为“添加所在文件夹”）和“取消”。所在文件夹是主目录或磁盘根目录时，“打开所在文件夹”不可用，并在悬停时说明原因。

“只打开这个文件”打开一个单文件标签页：标签页悬停提示显示完整路径，编辑区顶部显示一条信息横幅“这个文件不在已打开的文件夹中”，自动保存照常进行；文件树不变。单文件标签页不属于任何根目录：P0 切换文件夹时保留，不计入确认对话框中“会关闭”的标签页数量；它不随根目录记住，重启后不恢复。

验收：

- **ST-1** 首次启动显示“开始写作”和“打开文件夹”；打开文件夹后显示文件树和“选择一个文件开始写作”。
- **ST-2** 让保存失败（例如把文件设为只读）：状态栏显示“保存失败”，横幅显示原因和“重试”，标签页显示红点；恢复权限后点击“重试”，横幅消失，状态变为“已保存”。
- **ST-3** 保存在 300ms 内完成时，状态栏不出现“保存中”。
- **ST-4** 在另一个编辑器里修改一个已打开、已保存的文件：Nicole 自动载入新内容，并显示“已载入磁盘上的新内容”；Nicole 自己保存时不出现这条提示。
- **ST-5** 光标在第 20 行的某个词后面，外部在第 5 行前插入 3 行：载入后光标仍在同一个词后面（第 23 行），可见区域顶部仍是载入前的那一行。
- **ST-6** 在本地有待保存内容时从外部修改文件，出现外部修改横幅，自动保存暂停，直到用户做出选择。
- **ST-7** 从外部删除已打开的文件：出现删除横幅，内容仍在；点击“重新保存”后文件在原路径重新出现。
- **ST-8** 存在恢复副本时启动，先显示恢复对话框；用户选择之前，磁盘文件不被改写。
- **ST-9** P0 中打开另一个文件夹前出现确认；切回原文件夹后，原来的标签页恢复。
- **ST-10** 双击一个位于下载文件夹的 `.md` 文件，出现“这个文件不在已打开的文件夹中”的对话框；选择“只打开这个文件”后，文件树不变，文件可以编辑并自动保存。

## 浮层与面板

所有浮层使用同一套外观：`--surface-elevated` 背景，`--border-default` 边框，`--radius-card` 圆角，`--shadow-lg` 阴影，界面字体 13px。层级使用主题包的 z-index 变量：

| 浮层 | 位置 | 层级 | 打开方式 | 关闭方式 |
|---|---|---|---|---|
| 大纲 | 内容区宽度不小于 840px 时固定在右侧；否则临时浮在内容区右上角 | 布局内；浮动时为 `--z-popover` | 大纲开关、⌃⌘O | 大纲开关、⌃⌘O；浮动时还可以按 Esc、点击外部或点击标题 |
| 查找替换 | 正文区域右上角，距顶栏下边 8px、右边 14px，宽 380px；有格式工具栏时位于其下方；大纲固定显示时，右边对齐大纲的左边缘 | `--z-popover` | ⌘F 只显示查找行；⌥⌘F 同时显示替换行 | Esc |
| 全文搜索 | 替换侧栏中的文件树 | 布局内 | ⇧⌘F，或点击侧栏的搜索入口 | Esc，或清空输入框 |
| 命令面板 | 水平居中，距窗口顶部 72px，宽 `min(560px, 100% - 48px)`，下面有一层浅色遮罩 | `--z-overlay` | ⇧⌘P、⌘P、⇧⌘O | Esc，点击遮罩，或执行一条命令 |
| slash 菜单 | 锚定在光标下方，空间不够时翻到上方，宽 260px，最多显示 8 项 | `--z-popover` | 在行首或空格后输入 `/`，或输入法输出的 `、` | Esc，光标离开触发位置，查询没有匹配项，或执行一条命令 |
| 链接与图片弹框 | 锚定在元素下方，空间不够时翻到上方 | `--z-popover` | 见[链接与图片弹框](#链接与图片弹框) | Esc，或“完成” |
| 对话框（崩溃恢复、切换文件夹等） | 窗口中央，宽 440px，带遮罩 | `--z-modal` | 由状态触发 | 按钮；Esc 等同于“取消” |
| 原生右键菜单 | 鼠标位置 | 系统 | 右键 | 系统 |

规则：

- 同一时间只显示一个 `--z-popover` 层级的浮层，只有查找替换可以和 slash 菜单、链接弹框同时存在。打开命令面板或对话框时，关闭所有 `--z-popover` 浮层。
- Esc 只关闭最上层的浮层或临时界面，顺序从上到下为：对话框、命令面板、`--z-popover` 浮层、临时浮出的大纲、窄窗口下浮出的侧栏、全文搜索视图。都没有时，Nicole 不处理 Esc，交给编辑器（例如折叠多选区、取消输入法组合）。
- 所有浮层在窗口边缘内保留 8px 间距，不超出窗口。
- 浮层打开时焦点进入浮层，关闭后焦点回到打开前的位置。slash 菜单和沉浸模式下点击链接显示的弹框不抢焦点。
- 输入法组合期间（`KeyboardEvent.isComposing` 为真，或 `keyCode` 为 229），slash 菜单、命令面板和上面的 Esc 关闭顺序都不处理这次按键，Enter、↑、↓、Esc 等一律交给输入法。

### 查找替换

- 第一行：查找输入框（右侧有区分大小写和正则开关），右边是“4/12”样式的计数、上一个、下一个和关闭按钮。第二行（⌥⌘F 时显示）：替换输入框、“替换”和“全部替换”。
- 所有匹配用 `--status-warning-bg` 背景加 `--status-warning-border` 描边；当前匹配用 `--accent-soft` 背景加 `--focus-ring-color` 描边。
- 打开查找时，如果有选区且在一行之内，用选中的文字作为查找内容。

### 命令面板

- 三种入口共用一个面板，输入框开头的前缀决定模式，删掉或改写前缀可以在模式之间切换：
  - ⇧⌘P 打开时预填 `>`，为命令模式：列出命令注册表中的命令，右侧显示快捷键；
  - ⌘P 打开时不带前缀，为文件模式：列出所有根目录下的文件，最近打开的排在前面；
  - ⇧⌘O 打开时预填 `@`，为标题模式：列出当前文件的标题，选中后跳转。
- 搜索支持拼音模糊匹配（`pinyin-pro`，见[Slash 命令](slash-commands.md#搜索与排序)），最近用过的排在前面。
- 打开面板时保留编辑器选区，执行的命令作用于这个选区。

### slash 菜单

- 触发条件（包括中文输入法下的 `、`）、内置命令和排序见[Slash 命令](slash-commands.md)。
- 菜单顶部用浅色显示当前输入的查询，例如“/biao”。每项左侧是 22px 的示意（例如 `H2`），中间是名称，右侧是快捷键。
- 执行命令后删除触发字符和查询文字。查询没有匹配项时，菜单直接关闭。按 Esc 关闭菜单、光标离开触发位置，或者因为没有匹配项而关闭时，保留已经输入的 `/` 或 `、` 和查询文字，不做删除。

验收：

- **F-1** 按 ⌘F 打开 Nicole 的查找栏，不出现 CodeMirror 自带的查找面板；在有 slash 菜单时按 Esc，只关闭 slash 菜单，查找栏保留。
- **F-2** 打开命令面板时，slash 菜单和链接弹框会关闭；在命令面板中执行“加粗”时，作用于打开面板前的选区。
- **F-3** 在中文输入法下，于行首按 `/` 键（输出 `、`），打开 slash 菜单；在句中两个汉字之间输出 `、`，不打开菜单。
- **F-4** 光标在窗口底部附近时，slash 菜单翻到光标上方，不超出窗口。
- **F-5** 关闭任何浮层后，焦点回到打开前的位置；从编辑器打开的，光标位置不变。
- **F-6** 用 `、` 打开 slash 菜单后继续用拼音输入，在组合期间按 Enter：拼音按原样上屏，不执行菜单中的命令；组合期间按 ↑↓ 只切换候选词，不移动菜单选中项；组合期间按 Esc 只取消组合，slash 菜单保持打开。
- **F-7** 在命令面板的输入框中用拼音输入，组合期间按 Enter：拼音按原样上屏，不执行当前选中的命令。
- **F-8** 在 slash 菜单中继续输入，直到查询没有匹配项：菜单自动关闭，`/` 和查询文字原样保留在正文中；再输入的文字照常进入正文。在有匹配项时按 Esc，菜单同样关闭，已输入的文字保留。

## 右键菜单

- **正文**：不添加应用自己的菜单项。WebView 自带菜单中的“重新载入”“后退”“前进”要去掉；“检查元素”只在开发构建中保留；剪切、复制、粘贴以及 macOS 的查询、翻译、服务等系统项保留。用 Go 端的 `Page.OnContextMenu` 实现。
- **文件树、标签页、根目录**：使用原生菜单。页面根据右键位置组装菜单项（名称和快捷键从命令注册表读取），交给 Go 端用 `Menu.PopupAt` 显示。

| 位置 | 菜单项（── 表示分隔线） |
|---|---|
| 文件 | 新建文件、新建文件夹、重命名、移到废纸篓 ── 用默认应用打开（仅非 `.md` 文件）、在 Finder 中显示 ── 复制路径、复制相对路径 |
| 文件夹 | 新建文件、新建文件夹、重命名、移到废纸篓 ── 在 Finder 中显示 ── 复制路径、复制相对路径 |
| 文件树空白处 | 新建文件、新建文件夹 |
| 根目录分组标题 | 新建文件、新建文件夹 ── 在 Finder 中显示、复制路径 ── 从侧栏移除（P1） |
| 标签页 | 关闭、关闭其他、关闭右侧、关闭全部 ── 重新打开关闭的标签页 ── 在文件树中定位、在 Finder 中显示 ── 复制路径、复制相对路径 |

- 平台文字：“在 Finder 中显示”在 Windows 上为“在资源管理器中显示”，在 Linux 上为“在文件管理器中显示”；“移到废纸篓”在 Windows 和 Linux 上为“移到回收站”。系统不支持回收站时，改为“删除”，并先确认。
- 批量关闭标签页时，如果其中有保存失败、换行风格混合或已被删除的标签页，先显示确认对话框，列出这些文件，不直接丢弃内容。关闭单个这样的标签页时的确认见[外观与行为](#外观与行为)。
- 删除文件夹前显示确认对话框，说明其中的文件数量。

验收：

- **C-1** 在正文中右键，菜单中没有“重新载入”“后退”“前进”，也没有应用自己的菜单项。
- **C-2** 在文件、文件夹、空白处、根目录和标签页上右键，菜单项与上表一致，快捷键与[快捷键](#快捷键)表一致。
- **C-3** 在标签页上选择“关闭其他”，其中一个标签页保存失败时，先出现确认，列出该文件。
- **C-4** 在 Windows 上，菜单写“在资源管理器中显示”“移到回收站”。

## 快捷键

- 下表是默认键位的唯一出处。实现时，每条快捷键都写在命令注册表对应命令的“快捷键”字段里，slash 菜单、命令面板、格式工具栏、右键菜单和悬停提示都从注册表读取，不在其他地方另写键位（见[Slash 命令](slash-commands.md#命令注册表)）。
- 注册表的键位使用 CodeMirror 写法，`Mod` 在 macOS 上是 ⌘，在 Windows 和 Linux 上是 Ctrl。两个平台不只是 ⌘ 与 Ctrl 互换的命令（例如查找并替换、下一个匹配），以及有多个键位的命令（例如下一个标签页），按[命令注册表](slash-commands.md#命令注册表)“快捷键”字段的分平台、多键位写法登记。界面显示时按平台转换为符号或文字。
- Windows 和 Linux 的键位避开 Ctrl+Alt 组合，因为它在部分键盘布局上等同于 AltGr，会与输入字符冲突。

| 分类 | 命令 | macOS | Windows / Linux |
|---|---|---|---|

## 设置

设置以一个特殊的标签页打开，不新开窗口。设置标签页不属于任何根目录：切换文件夹时保留，重启后不恢复。全局设置存放在用户数据目录；工作区配置以后放在 `.nicole/`（见[产品范围](product.md#已定决策)）。

入口：

- 侧栏底部的设置按钮；
- ⌘,（Windows 和 Linux 为 Ctrl+,）；
- 命令面板中的“设置”；
- macOS 应用菜单中标准的“设置”项。

设置页的布局和完整的设置项还没有设计，在实现设置的 PR 之前单独讨论。下表只记录本文已经确定、需要放进设置的项：

| 分组 | 设置项 | 默认值 | 说明 |
|---|---|---|---|
| 外观 | 主题 | 跟随系统 | 可选“跟随系统”“亮色”“暗色”；状态栏的切换图标会把它设为与当前相反的明确值 |
| 外观 | 界面字体、阅读字体、代码字体 | 系统字体 | 见[主题与字体](theming.md#字体) |

## 视觉与动效

- **界面文字**：`--font-sans`，13px；次要文字 12px；根目录分组标题 12px 半粗体。正文只使用 `reading-*` 变量。
- **表面**：侧栏使用 `--surface-panel`；顶栏、编辑区和状态栏使用 `--surface-canvas` / `--reading-bg`；分隔线使用 `--border-subtle`。
- **交互态**：悬停使用 `--surface-subtle`；文件树选中项使用 `--accent-soft`；键盘焦点使用主题包的 `focus-ring` 工具类。
- **图标**：内联 SVG，16px，线宽 1.5，颜色为 `currentColor`；不引入图标字体或图标库。
- **禁用的效果**：不使用 `backdrop-filter`、窗口 `Vibrancy` 或 `Transparent`，因为它们会增加 GPU 和合成层的开销；不使用常驻的 `will-change`。
- **动效**：只有浮层的出现和消失使用透明度或位移过渡，时长不超过 `--duration-normal`；文件树展开、标签页切换和侧栏显示都没有动画。没有无限循环的动画，“保存中”也是静态的。`prefers-reduced-motion: reduce` 时取消全部过渡。
- **文字缩放**：界面字号乘以 `--mygo-text-scale`（见 MyGo 的无障碍变量），正文字号由阅读层设置决定。

验收：

- **V-1** Paper 和 Ink 下，所有界面文字对其背景的对比度不低于 4.5:1，图标、状态圆点和控件边框不低于 3:1。
- **V-2** 界面 CSS 中没有 `backdrop-filter`、无限循环的 `animation`，也没有常驻的 `will-change`。
- **V-3** 开启“减弱动态效果”后，浮层出现时没有过渡。

## 键盘与无障碍

- 所有可交互元素都能用 Tab 和 ⇧Tab 依次到达，键盘焦点使用主题包的 `focus-ring` 工具类，在 Paper 和 Ink 下都清晰可见。
- 文件树使用 `role="tree"` 和 `treeitem`，用方向键移动、展开和折叠，用[快捷键](#快捷键)表“文件树”一类的键位打开、重命名和删除。
- 标签栏使用 `role="tablist"` 和 `tab`，用 ←→ 在标签页之间移动焦点，Enter 或空格切换到该标签页。
- 对话框使用 `role="dialog"` 和 `aria-modal="true"`，打开时焦点进入对话框，Tab 只在对话框内循环（焦点陷阱），关闭后焦点回到打开前的位置。
- 只有图标的按钮（侧栏开关、大纲开关、设置按钮等）有 `aria-label`，内容与悬停提示相同。

验收：

- **A-1** 只用键盘，从首次启动完成“打开文件夹 → 在文件树中打开一个文件 → 再打开另一个文件 → 在两个标签页之间切换”，过程中每一步都能看到焦点在哪里。
- **A-2** 用辅助功能检查工具（例如 macOS 的辅助功能检查器）查看：文件树、标签栏和对话框分别报告为 tree、tab list 和 dialog，只有图标的按钮有名称。
- **A-3** 打开任一对话框后连续按 Tab，焦点不会离开对话框；按 Esc 或“取消”关闭后，焦点回到打开前的元素。

## 实现取舍

- **组件**：P0 全部手写，不引入组件库。需要的交互组件只有树、标签页、命令面板、菜单式浮层、弹框和对话框六类，规模可控，而且当前内存已经超出预算。
- **Reka UI**：它是不带样式的 Vue 组件库，可以省下焦点管理、焦点陷阱、方向键导航和 ARIA 属性的工作，但会增加 JS 体积和常驻内存。只有在手写的对话框或弹框无法通过无障碍验收时，才单独引入对应的组件，并在 PR 中附上引入前后的空载内存对比。
- **按需加载**：`pinyin-pro` 等只在命令面板、slash 菜单里用到的依赖，在第一次打开它们时才加载，不进入空载内存。
- **浮层定位**：手写。用 CodeMirror 的 `coordsAtPos` 取锚点，按“下方优先、空间不够翻到上方、限制在窗口内”的规则定位，不引入 Floating UI 一类的库。
- **原生菜单**：右键菜单用原生菜单，外观、键盘操作和平台习惯都由系统负责，也不占页面内存。代价是 macOS 的查询、翻译和拼写建议不会出现在文件树和标签页的菜单里；正文保留 WebView 自带的菜单，不受影响。
